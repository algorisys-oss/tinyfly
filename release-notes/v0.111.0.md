# v0.111.0 — Cricket field marking profiles and setup overlays

Released: 2026-10-13

The cricket builders now draw the limited-over restriction area around the two
wickets and expose marking dimensions as explicit JSON profiles.

## Added

- `markingProfile: 'icc-men' | 'icc-women' | 'mcc'` on field/clip builders and
  `CRICKET_MARKING_PROFILES` metadata. The default is ICC men, independently of
  the character cast. These are marking profiles, not full competition rules.
- Owned `fieldingArea` capsule metadata. `cricketFieldingAreaContains` classifies
  ground-plane reference points; `cricketFieldingPositions` and
  `cricketFieldingOverlay` generate optional static setup markers. An absent
  restriction area returns null rather than being counted as outside.
- Example profile selection and green/orange setup markers, preserving current
  story time, playback and zoom. Exported scene JSON includes the selected
  profile, region and optional markers.

## Fixed

- ODI/T20 ICC outlines use outward semicircles at the middle stump of each end,
  joined by straight sides, instead of a circle at the pitch midpoint. The
  existing fielding-circle object ID is retained. ICC men radius is 27.43 m;
  ICC women radius is 23 m. Test and MCC base-Law profiles omit that outline.
- ICC profiles paint the popping crease to 7.5 m on either side; MCC retains its
  1.83 m minimum. Wickets, pitch, crease offsets and return-crease positions
  remain consistent with the authored motion.
