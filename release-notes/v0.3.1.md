# v0.3.1

**Release Date:** 2026-07-07

Patch release fixing a double scrollbar in the editor's left panel.

## Highlights

- Fixed a duplicate vertical scrollbar on the Elements/Layers sidebar in Chrome

---

## Fixed

- **Left sidebar double scrollbar** - The left sidebar (`.editor-sidebar-left`)
  and the `ElementPanel` inside it both created a vertical scroll container,
  producing two side-by-side scrollbars in Chrome (Edge hid it via overlay
  scrollbars). The outer sidebar is now `overflow: hidden`, leaving
  `ElementPanel`'s own `.panel-content` as the single scroll region. The right
  sidebar is unaffected.

---

## Technical Details

### Changed Files

| File | Description |
|------|-------------|
| `src/editor/editor.css` | `.editor-sidebar-left` set to `overflow: hidden` |
