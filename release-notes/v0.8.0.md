# v0.8.0

**Release Date:** 2026-07-08

Minor release adding **keyframe multi-select and copy/paste** to the timeline, so
you can duplicate and rework whole groups of keyframes at once.

## Highlights

- **Multi-select keyframes** - Ctrl/Cmd-click keyframes (across tracks) to build
  a selection
- **Copy / paste keyframes** - Copy the selection and paste it at the playhead,
  preserving relative timing
- **Delete many at once** - Remove all selected keyframes with one keypress

## Added

- **Keyframe multi-selection** - `Ctrl/Cmd-click` adds or removes a keyframe from
  the selection; selected keyframes are highlighted in the timeline.
- **Copy / paste** - `Ctrl/Cmd+C` copies the selected keyframes; `Ctrl/Cmd+V`
  pastes them starting at the current playhead. Relative timing between copied
  keyframes is preserved, they return to their source tracks, and the pasted
  keyframes become the new selection.
- **Batch delete** - `Delete` / `Backspace` removes every selected keyframe.
- **Editor-store API** - `toggleKeyframeSelection`, `selectKeyframes`,
  `isKeyframeSelected`, `clearKeyframeSelection`, `copySelectedKeyframes`,
  `pasteKeyframes`, `deleteSelectedKeyframes`, `hasKeyframeClipboard`, and a
  `selectedKeyframes` state array.

## Changed

- Timeline keyframe highlighting now reflects the multi-selection.
- Keyboard shortcuts (copy/paste/delete) act on keyframes when keyframes are
  selected, and on elements otherwise.
