# v0.93.0

**Release Date:** 2026-10-07

Stick figures act on code, Animator vs Animation style: they leap onto lines,
point at them, swipe them away, grab and throw words, kick them, carry them
to other lines, push them along and write new code by hand. And tinyfly is
now easy for language models to write: a capability catalog generated from
the library, did-you-mean errors for wrong names, and docs and an agent skill
shipped in the package.

## Added

### Acting on code

- **`codePanel()`** (characters): a code listing as a canvas scene object with
  syntax colours for Go, Rust, C#, JavaScript, TypeScript and Python. Layout is
  fixed-width arithmetic, so its anchors are exact everywhere:
  `line(n, time?)`, `token(n, text)`, `spot(n, column, width?)`, `box`.
- **Code edits** recorded as tracks: `highlight`, `strike`, `remove` (styles
  `wipe`, `fly` — knocked off the panel, blurring — and `blur` — out of focus;
  the lines below close the gap), `type` (hidden lines), `insert` (type text
  into a line; the line makes room).
- **Words that come loose**: `piece(n, text)`, then `follow` (a path),
  `fling` (a spinning ballistic arc at the speed it was carried), `move`,
  `write` (type new text into its place) and `drop` (into another line; into
  its own line it slides and the text closes up behind it). `landing()` says
  where it will land.
- **`code.ride(tracks, figure, { ground })`**: a figure standing on a line is
  carried with it as gaps above close; a hop off a moved line lands back on it.
- **New beats**: `leap` (onto a new floor, `onto`), aimed `point`, `swipe`,
  `grab`, `throw`, `kick`, `put`, `write`, `push`; poses `duck` and `lie`.
  Beats that touch something report `contact` and `release` times.
- **`handPath()`**: where a figure's hand is over time, for carried things.
- **`shove` gait**: short steady steps that leave the arms still, for pushing.
- Arms aim from the body (lean and bend included), reaches stand where the arm
  just reaches, and `write` uses two-bone arm IK to trace a line.
- Gallery cards **Code Acting** (Go), **Code Refactor** (JavaScript),
  **Code Fix** (Rust) and **Code Tidy** (Python).

### Made for language models

- **`capabilities()` / `capabilitiesMarkdown()`** and
  **`npx @algorisys/tinyfly capabilities [--json]`**: every easing, track kind,
  canvas property (with units and ranges), stick-figure joint, pose,
  expression, gag, gait, beat action, dance, flip, hand shape, v2 character
  pose, code-panel language and edit, camera shot and teaching helper, read
  from the library itself.
- **`checkBeats()`** and **`npx @algorisys/tinyfly check beats.json`**: unknown
  actions, moods, joints and fields are errors naming what was probably meant
  (`"jumpp"` → `"jump"`, `expression` → `mood`, `duration` → `for`), plus
  missing fields an action needs and malformed values.
- **`describeTarget(target)`**, **`animatableProperties(target)`**,
  **`checkTracks(tracks, targets)`** and **`CANVAS_PROPERTIES`**: what any target
  can animate, and tracks checked against their targets (`rotation` →
  `rotate`, keys out of order, wrong kinds, out-of-range values). Custom
  targets describe themselves with `about`; the stick figure lists every joint
  and action, the code panel its props and edits.
- **`llms-full.txt`** in the repo (every doc, the course and the catalog), and
  `llms.txt` links pinned to the release tag.
- The npm package now ships **`docs/*.md`, `llms.txt`, `llms-full.txt` and an
  agent skill** (`skills/tinyfly/SKILL.md`). New guide:
  [Building Animations with an LLM](../docs/llm-guide.md).
- `editDistance`, `closestName` and `unknownName` in the engine.

## Changed

- **`scriptTracks()` throws on unknown names** instead of quietly holding (an
  unknown action) or ignoring them (an unknown mood).
- `codePanel` throws on an unknown language or remove style.
- Walks keep a raised arm still on either side: a left arm held forward (a
  negative angle) no longer swings.
- Script `effects` carry a `y` (the floor the dust is on).

## Fixed

- `jointsToScene` (and so `stickFigureAt`) left `fingertips` in the figure's
  own space.

## Testing

- Code panel: layout arithmetic, anchors after gaps close, every edit's keys,
  pieces, flings, drops, slides with reflow, rides (through hops and from the
  ground).
- Beats: the palm lands on grab, put and write targets within a pixel; the
  foot meets a kick's target; pushes keep both hands on the word.
- Did-you-mean checks for beats and tracks; `describeTarget` for shapes, the
  stick figure and the code panel; the catalog matches the library and every
  action it lists compiles.
- `llms-full.txt` is kept up to date by a test.

## Upgrade Notes

- **Beat scripts with wrong names now throw.** A script that used an unknown
  action (it used to hold) or mood (it used to be ignored) must be fixed; the
  error names the right one.
