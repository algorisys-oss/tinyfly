# v0.10.0

**Release Date:** 2026-07-11

Minor release that makes the preview honour the project canvas, so animations of
any aspect ratio — including a vertical 9:16 promo — render at true proportions.
Ships a new kinetic-typography showcase sample built for that format.

## Highlights

- **Canvas-aware preview** - The preview artboard now follows the project canvas
  size across the DOM, Canvas, and SVG renderers, and fits-to-view (scaling down
  as well as up), so non-default aspect ratios render correctly
- **Samples can set their canvas** - Loading a sample can resize the project
  canvas, so a sample carries its own intended aspect ratio
- **"Draw · Guess · Repeat" sample** - A vertical (360×640) app-promo beat:
  colour-swap scenes with per-letter words that pop in, ripple on a traveling
  wave, then slide out, under a drawn underline

## Added

- **`canvas` on samples** - `SampleDefinition` gained an optional
  `canvas: { width, height }`; `loadSample` calls `projectStore.setCanvas` when
  present (otherwise the current canvas is kept).
- **Draw · Guess · Repeat showcase sample** - Authored purely as data
  (elements + keyframe tracks) for a 360×640 canvas; plays on any renderer.

## Changed

- **Preview artboard is reactive** - `preview-panel` reads the artboard width and
  height from `projectStore.currentProject().canvas` instead of a hardcoded
  300×200. The DOM stage, the `<canvas>` element, and the SVG `viewBox` all size
  to the canvas, and fit-to-view now allows scales below 1 for tall canvases.
- A side effect: the **Project Settings** canvas-dimension control now updates the
  preview live (previously the stage stayed 300×200 regardless).

## Fixed

- Content authored for a canvas taller/wider than 300×200 is no longer clipped
  out of view in the preview.

## Technical Details

### Changed Files

| File | Description |
|------|-------------|
| `src/editor/components/preview-panel.tsx` | Artboard dims read reactively from the project canvas; DOM/Canvas/SVG sized to canvas; fit-to-view allows scale < 1; refit effect on canvas change |
| `src/editor/components/samples-dialog.tsx` | `loadSample` resizes the canvas when a sample declares one |
| `src/editor/editor.tsx` | Threads `projectStore` into `PreviewPanel` and `SamplesDialog` |
| `src/editor/samples/sample-definitions.ts` | Optional `canvas` on `SampleDefinition`; new "Draw · Guess · Repeat" sample (360×640) |

### Test Coverage

- 519 tests passing (unchanged; the preview change is UI/layout, verified live in
  the browser — the vertical sample loads at 360×640 and DRAW/LAUGH/REPEAT render
  centred and animate).
