# v0.28.0

**Release Date:** 2026-07-22

**Symbols now animate in your exports.** GIF / WebP / MP4 bake in a symbol's
nested animation *and* its swaps — the file matches the preview, lip-sync
included.

## Highlights

- **Nested animation in export.** A symbol with its own timeline now animates
  inside every instance in exported GIF / WebP / MP4 — not just the editor
  preview. Combine with animating the instance on the scene timeline and it
  travels while its insides move, all in the file.
- **Swaps in export.** Symbol-swap (lip-sync) is baked in: the exported video
  shows `set[floor(swapIndex)]` frame-by-frame.
- **Faithful placement.** Each instance renders under a transform that honours its
  own scene animation (position / rotation / scale), so animated instances land
  in the right place.

## How it works

A new `buildSymbolExportLayer` builds one export composite per symbol used (base
+ swap sets), each handling that symbol's shapes/images and flattening nested
symbols. Per export frame it picks the shown symbol (swap), applies the symbol's
timeline at `sceneTime mod symbolDuration`, and draws it under a `ctx` transform
that maps symbol-local space into the instance's (scene-animated) box. Non-symbol
elements composite exactly as before, so symbol-free exports are unchanged.

## Added

- `src/editor/utils/symbol-export-layer.ts` — per-frame animated symbol rendering
  for raster export.
- Export dialog renders the symbol layer on top of the main composite.

## Technical Details

| File | Description |
|------|-------------|
| `src/editor/utils/symbol-export-layer.ts` | Per-symbol composites + ctx-transform rendering, nested timeline + swap per frame |
| `src/editor/components/export-dialog.tsx` | Wire the symbol layer into GIF/WebP/MP4 export |

### Test Coverage

- 645 tests passing. The layer reuses the already-tested `expandSymbolInstances`
  / `shownSymbolId` helpers and the Timeline `getStateAtTime`; the canvas
  compositing itself is integration code (no new unit tests).

### Limitations

- **Embeds** and the **Canvas preview** still show the symbol's poster frame
  (static); this release covers **raster export**. Baking nested animation into
  embed HTML needs runtime nested playback in the embed and is a separate item.
- Instance **opacity** doesn't multiply into the symbol's own element opacity
  (the Canvas adapter sets alpha absolutely); instance width/height and skew
  animation aren't composed.
- **SVG** preview rendering of instances is still pending.
