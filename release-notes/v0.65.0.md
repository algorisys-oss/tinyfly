# v0.65.0

**Release Date:** 2026-09-14

You can now author teaching figures in the studio: steps and captions are edited
on the timeline, with no JSON by hand. This release also fixes everything the
first real rollout of embeds found.

## Added

### Steps and captions in the studio

- **Steps lane:**
  - A new row under the time ruler shows each step as a flag. Red flags pause, and a
    **?** marks a question.
  - Add a step at the playhead with **M** or **+**, or double-click the lane.
  - Click a flag to select it and move the playhead there. Drag it to retime it; a
    drag is one undo step.
- **Step inspector** (Properties):
  - label, time and id (renaming moves the captions; taken ids are refused);
  - pause here, and a question (adding one turns on pause);
  - captions per language, with a note of which languages are still missing;
  - delete.
- **Navigation:** **[** / **]** and ⏮ / ⏭ move between steps; Delete and Esc act on the
  selected step.
- **Carried everywhere:** saving, Copy JSON, file export and embeds all keep steps and
  captions. Every edit undoes.

### Embeds

- **`labels.stepFormat`** sets the visible step counter:
  `"Step {index} of {total}"`, `"第 {index} 步，共 {total} 步"`.
- **`data-markers="0,2300,3800"`** creates steps by time for a timeline written
  without markers. This removes glue code sites wrote when adopting embeds on
  existing content.

## Fixed

- **The Reveal row showed on figures with no question.** `.tf-ctl-question` set
  `display: flex`, which overrode the `hidden` attribute. Every element of the
  controls now honours `hidden`.
- **An empty caption strip on figures without captions.** Figures that draw step text
  inside the SVG got a blank 20px line under the bar. The caption line is now hidden
  when no step has a label or caption.
- **Loading two tinyfly bundles on one page replaced the first.**
  `tinyfly-player.iife.js`, `tinyfly-embed.iife.js` and `tinyfly.iife.js` now add to
  one `tinyfly` global.

## Changed

- **Docs:** reduced motion taking precedence over `initialFrame` (showing the final
  frame) is now documented.

### Test Coverage

- **Unit:** 2,012 tests passing (13 new), covering the marker helpers, store actions
  with undo, and the mount details.
- **Cross-browser (Chromium, Firefox, WebKit):**
  - New `editor-steps` check, which drives the real studio: M and +, inspector edits
    verified through Copy JSON, flag drag and undo, [ and ], and Delete.
  - `embed` check: now asserts, from computed styles, that the question and caption
    rows are hidden when unused.

---

## Upgrade Notes

- **Embeds:** with no captions, the caption line is no longer shown. Sites that hid it
  with `captions: false` can drop that workaround, as can any `[hidden]` CSS
  workaround for the question row.
