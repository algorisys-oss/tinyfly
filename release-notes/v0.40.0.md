# v0.40.0

**Release Date:** 2026-07-22

**Resize snapping** — resizing now snaps just like dragging.

## Highlights

- **Snap on resize.** The edge or corner you drag snaps to the grid, to other
  elements' edges/centres, and to the artboard — with the same pink guide showing
  what it caught.
- **Handle-aware.** Each handle snaps the edges it actually moves: **e** snaps the
  right edge, **n** the top, **se** both right and bottom, and so on.
- **Plays nicely with Shift.** Holding **Shift** to lock the aspect ratio turns
  snapping off for that drag, so aspect-lock and snapping never fight.

## How it works

Resize reuses the same tested `snap.ts` core as drag. On each move the handler
computes the driven edge's position, asks `snapAxis` for the nearest grid/element/
artboard line within the (scale-adjusted) threshold, and nudges the resize delta
so the edge lands on it. A small `RESIZE_EDGE` map says which edge each handle
drives per axis.
