# v0.32.0

**Release Date:** 2026-07-22

**Embedded animations now play symbols.** A single-scene embed animates every
symbol instance's nested timeline in the standalone player — shared/embedded
animations finally match the editor.

## Highlights

- **Animated symbols in embeds.** The **Embed** dialog (single scene) now emits
  symbol instances as containers the player animates, and ships each symbol's
  nested timeline alongside the animation. The player runs them per-instance,
  looped over the symbol's duration and synced to the main playhead — so a
  symbol's internal animation plays wherever the embed is placed. Previously
  instances were flattened to a static poster frame.

## How it works

- **Export:** `generateSymbolInstanceHtml` renders each instance as
  `<div data-tinyfly="…" data-tinyfly-symbol="…">` with a scaled inner wrapper;
  the embed passes the used symbols' timelines via the new `symbols` player
  option.
- **Player:** `TinyflyPlayer` gains `options.symbols`. On load it binds each
  `[data-tinyfly-symbol]` container to a private adapter driving its inner
  elements from the symbol's timeline at `mainTime % symbolDuration`. The scene
  timeline can still move the whole instance (the container is a normal target).

## Added

- `PlayerOptions.symbols` + `SymbolAnimation` type; nested-instance playback in
  the player.
- `generateSymbolInstanceHtml` (embed HTML for symbol instances).
- Embed dialog emits symbol containers + the `symbols` option.
