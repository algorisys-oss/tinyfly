# v0.3.0

**Release Date:** 2026-07-07

Product showcase samples and editor quality-of-life. This release adds a new **Algorisys** sample category with six rich, "viral infographic" style demos, and makes the status bar version chip a one-click hard reload.

## Highlights

- New **Algorisys** sample category with 6 product-showcase animations
- Status bar version chip now hard-reloads the app (cache-busting)
- Zero-config OSS publishing (default remote baked into the publish script)

---

## Added

### Algorisys Product Showcase Samples

A new `products` sample category (labelled **Algorisys** in the Samples dialog), each authored for the default 300×200 canvas using only the engine's public animation model:

- **TinyFly — Animation Engine** 🪁 — a spark flies along a keyframe timeline, lighting each keyframe as the logo assembles
- **YappyDraw — Draw Together** ✏️ — a pen sketches across a board, popping colorful strokes into place
- **HappyPaint — Splash of Color** 🎨 — paint blobs burst outward into a spinning palette, then the logo lands
- **ProPeak — Reach the Summit** ⛰️ — bars climb into an ascending trend, an arrow soars, and a growth badge pops
- **SkillzEngine — Level Up** ⚙️ — counter-rotating gears, filling skill bars, and a bursting level-up badge
- **Algorisys Ecosystem** 🌐 — the hero infographic: five product nodes orbit a central hub, connectors draw out, nodes pop in with labels

### Status Bar

- **Version chip hard reload** - Clicking (or pressing Enter/Space on) the `v{version}` chip triggers a cache-busting full page reload, so the latest build is always fetched. Keyboard-accessible with focus styling.

---

## Changed

- **Sample categories** - Added `products` to the category union and category helpers/labels
- **publish-oss.sh** - `OSS_REMOTE` now defaults to `https://github.com/algorisys-oss/tinyfly.git`, so `./scripts/publish-oss.sh --push` runs with no inline env var (override still supported)
