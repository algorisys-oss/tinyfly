# v0.39.0

**Release Date:** 2026-07-22

**Grid & snapping** — line elements up in seconds, with alignment guides that
appear as you drag.

## Highlights

- **▦ Grid.** Toggle a 20px grid overlay on the artboard (DOM preview).
- **🧲 Snap.** Dragging an element snaps its edges/centre to the grid, to other
  elements, and to the artboard centre — on by default, toggle off any time.
- **Pink alignment guides.** When a snap catches, a guide line shows exactly what
  the element lined up with.

Snapping considers, on each axis, the moving element's **left/centre/right** (and
**top/middle/bottom**) against every **other element's** edges and centre, the
**artboard** edges and centre, and the **grid** (while ▦ Grid is on). The pixel
threshold is divided by the preview scale, so it feels the same at any zoom.

Grid and snapping are **editor-only** — they never change the animation or the
saved JSON.
