# v0.89.0

**Release Date:** 2026-10-06

Cartoon acting: the same key poses, moved the way hand-drawn characters move.
Characters wind up before a move, overshoot and settle, overlap from the hips
out to the wrists, and dart their eyes ahead of the head. Gags, speed lines and
drawing on twos come with it. See [docs/acting.md](../docs/acting.md).

## Added

- **`actTracks(target, keys, { style })`** (`@algorisys/tinyfly/characters`):
  takes `poseTracks()` keys and returns tracks with the same ids, with acting
  applied:
  - anticipation;
  - overshoot that settles smoothly, or wobbles in the `snappy` style;
  - overlap by chain depth;
  - eyes that lead and dart;
  - blinks on head turns and idle blinks;
  - moving holds (the figure still ends on its last pose);
  - squash and stretch on jumps, read off `rise`.
  
  The output is plain keyframes. **`actCharacterTracks()`** does the same for
  v2 characters, and **`actKeyframes(keys, rig, options)`** works on any
  record of numbers.
- **`ACTING_STYLES`**: `full`, `snappy`, `limited` and `none`, each tunable
  (`{ base: 'snappy', overlap: 60 }`). **`STICK_ACTING_RIG`** and
  **`HUMAN_ACTING_RIG`** set what leads, what drags and how far each joint may
  wind up.
- **Gags as data**: `gag('take' | 'doubleTake' | 'windUp' | 'land' |
  'tremble' | 'deflate', { at, from, speed })` returns timed keys to splice
  into a story; also `GAGS` and `gagDuration()`. A key marked `act: false`
  passes through the acting pass as written.
- **Motion effects**:
  - `drawStickSmear()`: speed lines behind fast hands, feet and head, from
    `frame.stateAt`, so frames draw the same in any order;
  - `drawSpeedLines()` for any path;
  - `drawDustPuff()` and `drawImpactStars()`, driven by a 0–1 progress.
- **Drawing on twos**: the `drawingRate` setting on video scenes (12 = on
  twos at 24 fps) holds the timeline's poses for several frames. `draw` and
  `background` still get every frame's time. **`heldTime(time, rate)`**
  (engine) does the same anywhere else.
- **`resolvePoseKeys()`** and **`resolveCharacterPoseKeys()`** return the
  full pose at each key.
- Example `examples/headless-video/cartoon-acting.mjs`: the same story
  through `poseTracks()` and `actTracks()`, side by side.

## Upgrade Notes

- **No breaking API changes.** `poseTracks()` and `characterPoseTracks()`
  return the same tracks as before.
- The editor and the browser player do not use acting styles or
  `drawingRate` yet (planned, see todo.md Phase 36B).
