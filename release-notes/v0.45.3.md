# v0.45.3

**Release Date:** 2026-07-22

Pen-tool polish: snapping and corner points.

## Highlights

- **Pen points snap.** With **🧲 Snap** on, placing or moving a pen point snaps to
  the grid, your ruler guides, other elements' edges/centres, and the artboard —
  with the same pink alignment guides as element editing. Handles stay free so
  curves aren't constrained.
- **Alt = corner.** Hold **Alt** while dragging a handle to break symmetry: the
  opposite handle stays put, giving a cusp instead of a smooth point.

## How it works

`snapPenPoint` reuses the existing snap targets (`collectStaticSnapLines` +
`gridLinesFor` + `snapAxis`) for the anchor's x/y and publishes the caught guide
lines, so pen snapping is consistent with drag/resize snapping. The `cusp` branch
(Alt) simply skips mirroring the opposite handle while dragging.
