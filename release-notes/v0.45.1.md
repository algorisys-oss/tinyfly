# v0.45.1

**Release Date:** 2026-07-22

Pen-tool polish.

## Highlights

- **Backspace / Delete** removes the last point you placed while drawing — no need
  to cancel and start over after a misclick.
- **Close-hover cue.** The first anchor grows and turns cyan when the cursor is
  close enough to close the path, and the hint switches to “Click to close the
  path”, so it's obvious when a click will close vs. add a point.
