# v0.35.0

**Release Date:** 2026-07-22

The camera now works **everywhere** — not just the DOM preview, but Canvas/SVG
previews, raster export, and embeds.

## Highlights

- **Camera in export.** GIF / WebP / MP4 export applies the camera's pan / zoom /
  rotate per frame (the background stays fixed) — cinematic moves ship in the file.
- **Camera in embeds.** Single-scene embeds wrap the stage in a `Camera` layer the
  player animates; multi-scene sequence embeds get a per-scene camera layer in the
  sequencer — so embedded animations move with the camera.
- **Camera in Canvas & SVG previews.** Switching renderer keeps the camera move.

## How it works

A shared `camera.ts` reads the `Camera` state from the timeline and applies the
same transform three ways: a Canvas `ctx` transform (preview + export), an SVG
`<g transform>` (SVG preview), and a `data-tinyfly="Camera"` layer animated by the
adapter (DOM preview, player, sequencer) — all matching `transform-origin: center`
so the result is identical across renderers and output.

## Added

- `src/editor/utils/camera.ts` — `cameraFromState`, `applyCameraToCtx`,

- Camera applied in raster export (`export-dialog`), Canvas/SVG previews
