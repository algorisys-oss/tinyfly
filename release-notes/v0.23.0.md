# v0.23.0

**Release Date:** 2026-07-22

**Symbols + Library** land — the biggest Adobe-Animate-parity feature. Bundle
elements into a reusable **symbol**, then place instances; edit-once-update-
everywhere, all still plain JSON. This is Phase A, part 1 (create / place /
render); edit-in-place and nested playback follow.

## Highlights

- **Symbol Library.** A new **Library** panel at the bottom of the left sidebar
  holds reusable symbols, shared across every scene in the project.
- **Convert to Symbol.** Select elements → **+ Symbol** in the Library. The
  selection is bundled into a symbol and replaced on the stage with a single
  **instance** that looks identical to what was there.
- **Place instances.** Click a symbol's thumbnail to drop another instance on the
  current scene. Move/resize it like any element — resizing scales the symbol's
  contents to fit. Every instance references the same symbol.
- **Manage.** Rename (double-click), delete (blocked while instances are in use,
  with a live `×N` instance-count badge), and per-symbol thumbnails.

## What's under the hood

- **JSON-first, engine untouched.** A `SymbolDefinition` is a self-contained
  mini-scene (elements + intrinsic size + optional nested timeline) stored on the
  project (`project.symbols`, the Library). An instance is a new `symbol`
  scene-element referencing a `symbolId`. Everything serializes with the project
  exactly like scenes.
- **Rendering.** In the **DOM preview**, an instance expands its symbol's contents
  (poster frame) scaled into the instance box. Static for now — nested playback is
  a later slice.

## Added

- `SymbolDefinition` / `SymbolInstanceElement` types; `'symbol'` element type.
- `project.symbols` Library with migration (older projects default to `[]`).
- project-store Library API: `createSymbol`, `getSymbols`, `getSymbol`,
  `renameSymbol`, `updateSymbol`, `symbolInstanceCount`, `deleteSymbol` (guarded).
- scene-store: `addSymbolInstance`, `replaceElementsWithSymbol`.
- `LibraryPanel` component; **Convert to Symbol** orchestration in the editor.
- `element-bounds.ts` (bounding box + translate helpers).
- DOM-preview rendering of symbol instances.
- Docs: Animate-parity **UI plan** in the roadmap, a **symbols-and-library.md**
  design doc, and an **editor-guide** Symbols section.

### Test Coverage

- 634 tests passing (+7 symbol-library: create/clone/size/rename/update/
  instance-count guard/persistence).

### Known limitations (next slices)

- **Edit-in-place** (open a symbol to edit its contents + nested timeline) is not
  yet wired — you create from a selection and place instances.
- Instances render in the **DOM** preview only (Canvas/SVG renderers and
  embed/export expansion come with the rendering slice).
- **Nested playback** and **symbol-swap** (lip-sync) are later slices.
- Undoing a "Convert to Symbol" restores the elements but leaves the (unused)
  symbol in the Library.
