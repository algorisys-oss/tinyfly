# v0.15.0

**Release Date:** 2026-07-11

Minor release that improves **video export fidelity**: image and video layers now
export with `object-fit` and rounded corners, so a device-screen promo comes out
looking like the editor.

## Highlights

- **`object-fit` in exported video** - Image and video layers honour
  cover / contain / fill when composited into the export (previously always
  stretched to fill the box). A vertical clip in a phone screen now
  cover-crops instead of squashing.
- **Rounded corners in exported video** - A layer's `borderRadius` clips the
  drawn image/video, so a device screen's rounded corners show in the file.
- **Fonts ready before export** - Export waits for `document.fonts.ready` so
  custom webfonts render in the Canvas frames.

## Changed

- `CanvasAdapter` image targets gained `objectFit` and `borderRadius`; the image
  render path computes a cover/contain destination rect and clips to an
  (optionally rounded) box.
- The export composite passes each element's `objectFit` (image + video) and
  `borderRadius` (video) through to the adapter.

## Technical Details

### Changed Files

| File | Description |
|------|-------------|
| `src/adapters/canvas/canvas-adapter.ts` | `ImageTarget.objectFit`/`borderRadius`; object-fit + rounded-clip render |
| `src/editor/utils/export-composite.ts` | Pass through objectFit/borderRadius |
| `src/editor/components/export-dialog.tsx` | Await `document.fonts.ready` before recording |

### Test Coverage

- 534 tests passing (+3: cover centre-crop dest rect, contain letterbox dest
  rect, rounded-rect clip). Verified live: a Phone device with a video screen
  exported to an MP4 whose screen shows the clip cover-cropped with rounded
  corners, in sync (frame counter advancing).

### Known limitations (tracked in todo.md)

- Video sync still uses per-frame seeking (approximate for long clips).
