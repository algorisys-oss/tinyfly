# v0.5.0

**Release Date:** 2026-07-08

Minor release adding **animatable filters** and a **shine sweep** — rounding out
the text-animation toolkit with blur, glow, drop-shadow, and a metallic-style
highlight that travels across the glyphs.

## Highlights

- **Animatable filters** - `blur`, `glow` (+ colour), and drop-shadow, composed
  identically across the DOM, SVG, and Canvas renderers
- **Filter presets** - Blur In, Drop Shadow, and a real (now actually glowing)
  Glow Pulse
- **Shine sweep** - A highlight sweeps across text, clipped to the glyph shapes,
  while the base colour stays visible (DOM renderer)

---

## Added

- **Filter properties** - New animatable properties `blur`, `brightness`,
  `glow` (+ `glowColor`), and `shadowX` / `shadowY` / `shadowBlur`
  (+ `shadowColor`). A shared `composeFilter()` builds the filter string so all
  three adapters render filters the same way.
  (`src/adapters/filter-utils.ts`)
- **Filter presets** - **Blur In** (entrance), **Drop Shadow** (emphasis), and an
  upgraded **Glow Pulse** that now renders a genuine coloured glow.
- **Shine sweep** - A new animatable `shine` property (0..1) drives a highlight
  band across text, clipped to the glyphs via `background-clip: text` with the
  base colour preserved underneath. Exposed as the **Shine Sweep** text preset.
  (`DOMAdapter.applyShine`)

## Changed

- **Glow Pulse** now animates a real `glow` filter (previously only scale +
  opacity).

## Fixed

- **Colour-valued preset keyframes** - `resolvePresetKeyframe` no longer runs
  `parseFloat` on non-numeric strings, so colour values (e.g. `#66d9ff`) in
  preset tracks are passed through intact instead of becoming `NaN`.

## Renderer Support

| Effect | DOM | SVG | Canvas |
|--------|-----|-----|--------|
| Filters (blur / glow / drop-shadow) | ✅ | ✅ | ✅ |
| Shine sweep | ✅ | — | — |

Shine relies on `background-clip: text`, which has no clean SVG/Canvas
equivalent yet; it is DOM-only for now.

## Upgrade Notes

Upgrade from v0.4.0:

1. No breaking changes — all additions are backwards-compatible
2. New filter/`shine` properties are optional; existing animations are unaffected
