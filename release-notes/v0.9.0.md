# v0.9.0

**Release Date:** 2026-07-08

Minor release that makes the preview stage much bigger: it now scales to fill the
available area, and a new **Maximize** mode fills the whole window.

## Highlights

- **Fit-to-view stage** - The 300×200 artboard scales up to fill the preview
  area instead of sitting small in the middle
- **Maximize preview** - One click fills the window with the stage; play/stop and
  exit from a floating bar, or press **Esc**

## Added

- **Fit-to-view scaling** - The preview stage is scaled (up to 8×) to fill the
  available space, computed from the container size and kept current with a
  `ResizeObserver`.
- **Maximize mode** - A **⛶ Maximize** button in the preview header expands the
  preview to a full-window overlay with a floating **▶ / ■ / ✕** control bar;
  **Esc** or **Restore** returns to the normal layout.

## Changed

- Pointer interactions (drag, resize, rotate, path-point edit) now divide
  client-space movement by the current preview scale, so editing stays
  pixel-accurate at any zoom.

## Technical Details

### Changed Files

| File | Description |

### Test Coverage

- 519 tests passing (unchanged; this is a UI/layout change, verified live in the
