# v0.44.0

**Release Date:** 2026-07-22

**Sprite-sheet export** — every frame in one PNG grid, ready for game engines.

## Highlights

- **Sprite format in Export.** Choose **Sprite** to render the animation as a
  single PNG grid (up to 8 columns) plus a JSON metadata file.
- **Portable metadata.** The JSON carries frame size, columns/rows, frame count,
  fps, and duration — exactly what Phaser, Unity, Godot, PixiJS, or a custom
  `<canvas>` player need to slice and play the sheet.
- **Transparent option.** Turn on Transparent for an alpha PNG.
- **Full-fidelity frames.** Reuses the same per-frame renderer as GIF/WebP/MP4,
  so shapes, text, paths, images, video layers, symbols, and the camera all
  composite in.

## Metadata

```json
{ "frameWidth": 200, "frameHeight": 200, "columns": 8, "rows": 4,
  "frames": 30, "fps": 30, "durationMs": 1000 }
```

Frames pack left-to-right, top-to-bottom, sampled evenly across the duration
(`i / frames`) so a looping clip doesn't repeat the first pose.
