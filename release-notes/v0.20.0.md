# v0.20.0

**Release Date:** 2026-07-22

The timeline gains a second personality: a **Curves (graph) editor** next to the
Dope Sheet. See — and shape — the motion between keyframes, not just its timing.

## Highlights

- **Curves view.** A **Dope Sheet | Curves** switch sits above the timeline.
  In Curves, every numeric track (x, y, opacity, scale, rotate, width…) is drawn
  as a **value-over-time curve**, normalized to its own range, with the **real
  easing** sampled between keyframes — so an `ease-in-out` reads as an S-curve,
  a bounce as an overshoot.
- **Edit on the curve.**
  - **Drag keyframe points in 2D** — horizontally to retime, vertically to change
    the value.
  - **Drag the amber easing handles** on a selected keyframe to shape the
    cubic-bezier between it and the previous keyframe (a named easing converts to
    a custom curve the moment you grab a handle).
  - **Double-click** an empty lane to add a keyframe at that time/value.
  - **Ctrl/Cmd-click** points to multi-select (parity with the Dope Sheet).
- **Lossless switching.** Both views share the same editor store — playhead,
  zoom, scroll and selection — so flipping between them never loses your place.
  Non-numeric tracks (colour, motion-path, arrays) can't be a single curve and
  are noted at the bottom; edit those in the Dope Sheet.

## Fixed

- **No more blank strip on the right.** A header/toolbar wider than the window
  used to force a horizontal **page** scroll, revealing a white gap when you
  resized or scrolled. The page no longer scrolls horizontally (`overflow-x`
  clamped at the root); the header and toolbar **wrap** instead of overflowing.

## Added

- **`CurveView`** (`src/editor/components/curve-view.tsx`) and **`TimelinePanel`**
  (`timeline-panel.tsx`) — the graph editor and the Dope Sheet / Curves switch.
- **`curve-math.ts`** — pure, tested helpers: `isNumericTrack`, `paddedRange`,
  `sampleCurve` (eased sampling with flat lead-in/tail-out), and
  `easingToBezierPoints` (named-easing → cubic-bezier approximations for handles).

### Architecture

Purely an editor-layer addition — the engine is untouched. The curve editor
reads the exact same tracks the Dope Sheet does; keyframe `value`, `time`, and
cubic-bezier `easing` are already first-class in the JSON, so the graph is a new
*view*, not a new data model. Curves are drawn with the engine's own
`getEasingFunction`, so what you see matches playback.

### Test Coverage

- 627 tests passing (+14 in `curve-math`: numeric-track detection, padded range,
  eased sampling with lead-in/tail-out, and easing→bezier mapping).
