# v0.119.1 — ML figures tolerate a non-finite count

Released: 2026-10-16

A patch to v0.119.0. v0.119.0 was tagged for the CDN but not published to
npm; this release carries the same features plus the fix below.

## Fixed

- `classifier`, `kmeans`, `descent` and `network` items no longer throw when
  their epochs, iteration, steps or flow value is NaN or ±∞; they treat it as 0.
  A page clock that briefly read a negative time (a frame's timestamp can come
  before the loop's start) could produce NaN.

## Validation

- A new test feeds NaN and ±∞ into each item.
- All tests pass.
