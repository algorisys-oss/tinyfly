# v0.28.2

**Release Date:** 2026-07-22

Two editor fixes: the demo animation now actually shows, and the timeline pane
stops clipping its track rows on short windows.

## Fixed

- **"Timeline runs but nothing animates" on a fresh/reloaded project.** The
  first-run demo timeline shipped `box` tracks with **no `box` element**, so it
  played but nothing moved. New projects now create the demo box, and older
  projects that hit this (a saved `box` timeline with zero elements) **self-heal
  on load** — the box is recreated so the animation is visible again.
- **Cramped/clipped timeline on short windows.** The preview's minimum height was
  large enough that, combined with a non-shrinking timeline, the track rows got
  pushed below the viewport (looked like "no scroll"). The preview minimum is
  smaller and the timeline can now shrink to fit — its track list scrolls
  internally, so the ruler and rows always stay on screen.

## Technical Details

| File | Description |
|------|-------------|
| `src/editor/editor.tsx` | Demo box element + self-heal for orphaned `box` timelines |
| `src/editor/editor.css` | `.editor-preview` min-height 200→120; `.editor-timeline` shrinkable |

No engine or test changes — 645 tests passing.
