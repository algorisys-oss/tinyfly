# v0.68.1

**Release Date:** 2026-09-15

The script-tag examples in the docs pointed at an old release. They now point at this one,
and a test stops them from falling behind again.

## Fixed

### Script tags in the docs pinned to an old release

- **What was wrong:** Getting Started, GSAP Compatibility, Code Examples, the Editor Guide
  and Teaching showed `tinyfly@v0.66.0` in their jsDelivr script tags. Only the README's
  links were updated at each release, so anyone copying from the docs got a build two
  releases old.
- **Now:** every pinned CDN link in `docs/` and the README names the current version.
- **Keeping it that way:** a test in `src/docs/llms-text.test.ts` fails when any pinned CDN
  link doesn't match the version in `package.json`, so a version bump that misses one fails
  the test run.

## Technical Details

| File | Description |
|------|-------------|
| `docs/getting-started.md`, `gsap-compat.md`, `examples.md`, `editor-guide.md`, `teaching.md`, `README.md` | CDN pins |
| `src/docs/llms-text.test.ts` | "CDN pins in the docs point at this version" |

## Upgrade Notes

- **No breaking changes.** Docs and tests only; the engine and bundles are the same as
  v0.68.0. v0.68.0 was tagged but not published to npm, so npm goes from 0.67.1 to 0.68.1.
