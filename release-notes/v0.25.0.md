# v0.25.0

**Release Date:** 2026-07-22

**Nested symbol playback** — symbols with their own timeline now animate inside
every instance. Reusable *animations*, not just reusable art.

## Highlights

- **Nested playback.** Give a symbol its own timeline (edit it in place and add
  tracks), and every **instance** plays that animation inside its box as the
  scene plays — synced to the scene playhead and looped over the symbol's
  duration.
- **Nested motion.** Animate the *instance* on the scene timeline (move / scale /
  rotate the whole thing) while its insides animate on the symbol timeline — the
  instance travels while its contents move. This is the compositional payoff of
  symbols: build a walk cycle once, then send it across the stage many times.
- **Deterministic & synced.** All instances of a symbol show the same nested
  frame at a given scene time — pure function of time, no per-instance state.
  Works while playing and while scrubbing.

## How it works

Each symbol instance with a timeline gets a private DOM adapter bound to its
expanded inner elements; on every frame the preview evaluates the symbol's
timeline at `sceneTime mod symbolDuration` and applies it to that instance's
contents. The engine is untouched — the symbol's timeline is the same
`TimelineDefinition` JSON as any scene's.

## Added

- Per-instance nested playback in the DOM preview (`preview-panel.tsx`):
  `rebuildInstanceAdapters` + `applyInstanceStates`, hooked into the existing
  render/animation loop and rebuilt when elements or symbols change.

### Notes & limitations

- **DOM preview only** for now — Canvas/SVG instance rendering and embed/export
  expansion are still to come.
- Instances are **synced** (all show the same nested frame at a given scene
  time); independent per-instance offsets/speeds are a later enhancement.
- A symbol element with a **base rotation *and* an animated rotate track** lets
  the animated transform win (same tradeoff the top-level adapter makes).

### Test Coverage

- 634 tests passing (the engine `getStateAtTime` this builds on is covered by the
  Timeline suite; nested playback is preview-layer integration over it).

### Still to come (Phase A)

- **Symbol-swap** (animate which symbol an instance shows — lip-sync).
- **Canvas/SVG** instance rendering + embed/export expansion.
- Undo of "Convert to Symbol" also removing the orphaned symbol.
