# v0.33.0

**Release Date:** 2026-07-22

**Multi-scene embeds animate symbols too.** The sequencer now runs each symbol
instance's nested timeline, matching the single-scene player (v0.32.0).

## Highlights

- **Animated symbols in sequence embeds.** A multi-scene embed
  (`tinyfly.playSequence`) now plays every symbol instance's internal animation
  within each scene — synced to that scene's playhead and looped over the
  symbol's duration, across scene transitions. Previously sequence embeds
  flattened symbols to a static frame.

## How it works

- **Export:** `exportSequence` emits symbol instances as
  `data-tinyfly-symbol` containers (via `generateSymbolInstanceHtml`) and ships
  the used symbols' nested timelines on the sequence (`SequenceDefinition.symbols`).
- **Sequencer:** on `renderScene`, each `[data-tinyfly-symbol]` container gets a
  private adapter bound to its inner elements; the frame loop drives them from the
  matching symbol timeline at `sceneTime % symbolDuration` (for both the A and B
  scene slots during transitions).

## Added

- `SequenceDefinition.symbols` (`SequenceSymbol`); per-slot nested playback in the
  sequencer.
- `exportSequence` emits symbol containers + ships symbol timelines.

## Technical Details

| File | Description |
|------|-------------|
