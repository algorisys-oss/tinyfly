# v0.72.0

**Release Date:** 2026-09-27

Characters and voice-over for video from code. A poseable stick figure you drive with
timeline tracks, and narration timed from your recorded clips instead of typed durations.

```js
import { stickFigureTarget, poseTracks } from '@algorisys/tinyfly/characters'
import { voiceNarration } from '@algorisys/tinyfly/headless'
```

## Added

### `@algorisys/tinyfly/characters`

- **A stick figure made of numbers:** a pose is joint angles plus `mouth`, `smile` and
  `blink`, so any two poses blend and every joint can be a keyframe track.
- **Ready-made poses:** `POSES` has rest, wave, cheer, shrug, point, think, handsOnHips,
  sad and surprised; `pose({ ... })` overrides single joints.
- **Motion:** `blendPose`, `walkPose(phase)` for a walk cycle, `talkingMouth(time)` for
  deterministic chatter.
- **On a timeline:** `stickFigureTarget()` is a `custom` canvas target whose props are the
  pose plus `walk`, `walking` and `talk`; `poseTracks(target, keys)` turns a list of named
  or partial poses into keyframe tracks.
- `drawStickFigure(ctx, pose, style)` draws one directly onto any Canvas 2D context.

### Narration audio

- `voiceNarration(scenes, { output })` decodes each line's recording with ffmpeg, times the
  lines from their sample counts and writes the whole narration as one sample-aligned WAV.
  It returns the plan (cues, scenes, duration) and the WAV path to use as the scene's
  `audio`.
- The pure steps are exported too: `assembleNarration(plan, clips, sampleRate)` and
  `encodeWav(samples, sampleRate)`; `decodeAudio(file)` reads any audio ffmpeg can.

### Benchmark

- One scene of a published pycairo video, ported call for call: drawing takes 4.5 ms per
  1080p frame against Cairo's 20.3 ms, the stills match, and the finished MP4 takes about
  as long (the x264 encoder sets the pace). Details in
  [Rendering Video from Code](../docs/video-rendering.md).

## Changed

- **Stills are taken mid-line:** when a scene has captions, `--stills` / `renderStills()`
  take each still halfway through a spoken line rather than halfway to the next marker,
  so the frame shows what is on screen while the line is heard. Scenes without captions
  are unchanged.
- `CaptionCue` has an optional `id` (narration cues already carry one); it names the still.
- The stick-figure example scene now uses `@algorisys/tinyfly/characters`.
- The README's entry-point table says what the browser bundle includes and leaves out.
