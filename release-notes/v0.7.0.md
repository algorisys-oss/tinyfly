# v0.7.0

**Release Date:** 2026-07-08

Minor release adding a **Video** element and carrying **audio/video into
embeds**, so media plays in sync both while editing and wherever an animation is
embedded.

## Highlights

- **Video element** - Add a video to the canvas; it renders its frames and stays
  in sync with the timeline (source, fit, start time, volume, mute, loop)
- **Media in embeds** - Exported/embedded HTML now includes audio/video, and the
  player auto-discovers and syncs it — no wiring required

## Added

- **Video scene element** - `video` element type with `src`, `objectFit`,
  `volume`, `muted`, `loop`, and `startTime`. Add it from the element panel;
  edit it in the property panel; it renders as a positioned `<video>` in the
  preview and syncs to the timeline (starting at `startTime`).
- **Embedded media playback** - The editor's HTML export now emits `<audio>` and
  `<video>` tags marked with `data-tinyfly-media` and `data-tinyfly-start`. On
  `load()`, `TinyflyPlayer` discovers these and keeps them in sync through
  play / pause / seek / stop — so embeds play their audio and video in time.
- **`syncMediaElement()`** - A shared, start-time-gated sync helper (exported
  from `tinyfly/player`) used by both the editor preview and the player, so both
  behave identically.

## Changed

- The editor preview's media handling now covers both audio and video via one
  registry and the shared `syncMediaElement` helper.
