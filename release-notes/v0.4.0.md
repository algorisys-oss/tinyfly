# v0.4.0

**Release Date:** 2026-07-08

Minor release bringing Adobe Animate-class **text animation** to the editor:
per-letter staggering, a typewriter effect, and clip/mask reveals — all built on
the same JSON-first, API-first engine.

## Highlights

- **Per-letter text animation** - Split a text element into letters and fan any
  preset across them with a stagger, the way Animate builds drop, cascade, and
  wave effects
- **Typewriter effect** - Character-by-character reveal with an optional blinking
  cursor that steps along; the timeline auto-extends to fit
- **Clip/mask reveal** - Animatable clip-inset wipes elements into view,
  consistently across the DOM, SVG, and Canvas renderers
- **9 new presets** - 5 per-letter presets (Drop & Bounce, Cascade Up, Wave,
  Assemble, Pop In) and 4 reveal/wipe presets (Reveal Right/Left/Up/Down)
- **Editor scrollbar polish** - Fixed a double scrollbar and a stray horizontal
  scrollbar in the right sidebar

---

## Added

- **Split text into letters** - `sceneStore.splitTextElement()` breaks a text
  element into one text element per glyph (Animate-style "break apart"),
  positioned to reproduce the original layout. Measurement is deterministic and
  works headlessly. (`src/editor/utils/split-text.ts`)
- **Staggered presets** - `editorStore.applyPresetStaggered()` fans a preset
  across an ordered list of targets, each offset by a per-letter delay. Exposed
  in the Preset Panel via a **Per-letter stagger** toggle (also works across a
  multi-selection).
- **Per-letter presets** - Letter Drop & Bounce, Cascade Up, Wave, Assemble, and
  Pop In, tuned to shine when staggered.
- **Typewriter effect** - A **Typewriter** control (speed + optional blinking
  cursor) that splits the text, reveals each letter in sequence, adds a cursor
  that steps to each glyph, and auto-extends the timeline.
  (`src/editor/utils/build-typewriter.ts`)
- **Clip/mask reveal** - New animatable properties `clipTop`, `clipRight`,
  `clipBottom`, `clipLeft` (percent 0-100), composed into a clip-inset reveal in
  the DOM, SVG, and Canvas adapters.
- **Reveal presets** - Reveal Right / Left / Up / Down (Entrance). Combine with
  per-letter stagger for a cascading, letter-by-letter mask reveal.
- **"Letter Drop & Bounce" sample** - A data-authored showcase (Text category)
  that plays anywhere the engine runs.
- **Timeline `setDuration()`** - The engine timeline can now have its explicit
  duration set/extended (and reverted to auto-calculated).

## Changed

- **Right sidebar layout** - The Properties and Animation Presets panels now each
  scroll internally within a non-scrolling sidebar; category tabs wrap instead of
  overflowing.

## Fixed

- **Right sidebar double scrollbar** - The outer sidebar and the preset panel both
  scrolled; the outer sidebar is now `overflow: hidden` with each panel scrolling
  within itself.
- **Stray horizontal scrollbar** in the Properties panel - Inputs kept their
  intrinsic min-width and overflowed the narrow sidebar; they now shrink to fit
  (`min-width: 0`).
- **Editor store state isolation** - `createEditorStore()` cloned its default
  state so multiple instances no longer share a backing object.
