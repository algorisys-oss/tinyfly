# v0.75.0

**Release Date:** 2026-10-02

Pencilmation-style animation. Lines can be drawn in pencil that boils (redraws its wobble a
few times a second), an eraser can rub out part of a figure or a drawing, the stick figure
squashes, stretches and gets rubber-hose limbs, and the animator's hand draws strokes on.
Everything stays deterministic: the wobble is seeded by time, never `Math.random`.

## Added

- **Pencil sketch style:** `sketchPen(ctx, style, time)` draws hand-drawn lines, curves,
  circles and ellipses (several passes, bowed segments, circles that overshoot) with line
  boil. `style: { roughness, passes, boil, seed }`. Every stroke takes a `progress` (0..1)
  to draw it on, and the partial stroke lies exactly on the finished one.
- **Sketched stick figure:** `StickStyle.sketch`; `drawStickFigure(ctx, pose, style, time)`.
- **Sketched canvas shapes:** rect, circle, line and path canvas targets take `sketch`
  (pencil outline, clean fill) and `drawOn` (0..1, the outline drawn on; the fill appears
  once it is complete). `pathOutline()`, `rectOutline()`, `drawOutline()`.
- **Erasing:** `erasable(target, { path, width, hand? })` adds an `erase` prop (0..1) that
  rubs a custom target out along a path; `withErased()` / `clipErased()` for drawing done in
  code; `scrubPath()`, `drawEraser()`. Clip-based, so no offscreen canvas.
- **Squash and stretch:** a `stretch` pose field (body and legs scale, arms less, the head
  keeps its area, feet stay on the ground); `crouch` and `jump` poses.
- **Rubber-hose limbs:** `StickStyle.rubber` (0 jointed to 1 curves through the joint), also
  a `rubber` prop on `stickFigureTarget` so a track blends it; `rubberLimb()`.
- **The animator's hand:** `drawnPathTarget({ path, smooth, sketch, hand })` draws a stroke
  on from a `draw` track while a cartoon hand holds the pencil at its end; `drawHand()`,
  `drawPencil()`, `circlePath()`.
- **Polyline helpers:** `partialPath()`, `pointAlong()`, `pathLength()`.
- **Editor:** a **Pencil Sketch** section in Properties for rectangles, circles, lines and
  paths (Canvas preview and GIF / WebP / MP4 export). **Write On** now covers rectangles,
  circles and lines as well as paths.
- **Examples:** a **Pencil Sketch** gallery card, and four video scenes in
  `examples/headless-video/`: `pencil-sketch.mjs`, `eraser-gag.mjs`, `rubber-hose.mjs`,
  `drawing-hand.mjs`.

## Changed

- The DOM and SVG adapters ignore `drawOn` (a Canvas-only property) instead of writing it
  onto the element's style.

## Upgrade Notes

- **No breaking API changes at runtime.** `StickPose` gained a `stretch` field; a pose
  written without it draws unstretched, but TypeScript code that builds a full `StickPose`
  literal must add `stretch: 1` (or build it with `pose()`).
- `stickFigureTarget` props now include `stretch` and `rubber`.
