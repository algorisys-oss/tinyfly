# v0.38.0

**Release Date:** 2026-07-22

**Onion skinning** — see the arc of a move while you edit a single frame.

## Highlights

- **🧅 Onion skin (Canvas renderer).** Faint ghost frames of the moving elements
  appear just before and after the playhead — brightest nearest the current time,
  fading out with distance. Scrub and watch a bounce or swing take shape.
- **Editor-only.** Ghosts draw only while paused and are never part of the
  exported animation or the saved JSON.
- **Camera-aware.** Each ghost is drawn through its own camera transform, so it
  lands exactly where that frame actually appears.

## Why Canvas only

The Canvas renderer redraws the whole stage cheaply at several opacities per
frame; DOM/SVG would need cloned element trees per ghost. So onion skin is
Canvas-only for now — switch the renderer to **Canvas** and the 🧅 Onion toggle
appears in the preview header.
