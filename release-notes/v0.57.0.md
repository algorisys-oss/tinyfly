# v0.57.0

**Release Date:** 2026-09-14

Finishes the award-site toolkit: snapping, markers and horizontal-section triggers
for scroll triggers, image-sequence scrubbing, page transitions with shared elements,
and custom eases.

## Added

### Scroll triggers: `snap`, `markers`, `containerAnimation`

```js
const row = live
  .timeline({ scrollTrigger: { trigger: '.work', start: 'top top', end: () => `+=${travel()}`, pin: true, scrub: true, snap: 1 / 3 } })
  .to('.track', { x: () => -travel(), ease: 'none' })

live.from('.panel h3', { y: 20, opacity: 0, scrollTrigger: { trigger: '.panel', containerAnimation: row, start: 'left 80%' } })
```

- **`snap`**: a progress step, a list of points, `'labels'`, a function, or
  `{ snapTo, duration, delay, ease }`.
  - It settles once scrolling stops, carrying a flick on to the next point.
  - It gives way at once to wheel, touch, pointer or key input.
- **`markers`**: start and end lines for developing. They also work inside scrolling
  elements.
- **`containerAnimation`**: triggers inside a sideways-sliding pinned section. Their
  horizontal positions are solved against the row's own motion.
- **`ScrollDriver`** gains `snap`, `markers`, `container`, `startOffset` and
  `endOffset`.
- **Pure helpers:** `snapProgress` and `containerProgressAt`.

### `live.imageSequence`

A canvas showing frame N of a numbered image sequence. Tween or scrub its `frame`:

- frames load nearest-first, a few at a time;
- the closest loaded frame is drawn meanwhile;
- `fit` is `cover` or `contain`;
- the canvas matches the device pixel ratio and follows resizes.

### `live.pageTransition`

`await live.pageTransition({ from, to, update, shared: '[data-flip-id]' })` handles a
client-side route change:

- the old view animates out, then the update runs (it may be async);
- shared elements fly across, animated separately from the page around them;
- the new view animates in.

`native: true` uses the View Transitions API where available.

### Custom eases

- **`CustomEase.create(name, pathData | bezierPoints)`**: any scale or y direction,
  normalised, so curves from design tools work as they are.
- **`CustomBounce.create(name, { strength })`**: physically timed rebounds.
- **`CustomWiggle.create(name, { wiggles, type })`**: returns to the start.
- **Also available** as `live.customEase` / `customBounce` / `customWiggle`, and
  on the `tinyfly` global.
- **Serialization:** a single cubic stays an exact cubic-bezier. Other curves are
  always sampled into keyframes.
- **Engine generators:** `customEase`, `customBounce`, `customWiggle`.

### Demos

Four new demos, 41 in total:

- Image Sequence Scrub

- Pinned Horizontal Scroll, which now snaps to panels and reveals titles through

## Fixed

- **`onUpdate` when scrubbed:** it now fires when a live timeline is moved by
  `progress()` or `seek()`, which is how scroll scrubbing moves it.
- **`bakeEasing`:** it now ends on the ease's own final value, so a wiggle ends at
  the start instead of the target.
- **Object targets:** any object is accepted, including class instances with
  setters.
- **Page transitions:** the new page's slide-in no longer drags shared elements
  along.
