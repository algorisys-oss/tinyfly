# v0.45.0

**Release Date:** 2026-07-22

**Pen tool** — draw custom paths. This completes **Phase C**.

## Highlights

- **✒️ Pen** in the DOM preview header. **Click** to drop anchor points (straight
  segments), **click-drag** to pull out a smooth bezier curve as you place a
  point.
- **Finish naturally.** Click the highlighted **first point** to close the path
  (filled), or press **Enter** / **double-click** for an open path (stroked).
  **Esc** cancels.
- **Live feedback.** The in-progress path, a rubber-band to the cursor, anchors,
  and bezier handles are drawn as you go.
- **Just a path.** The result is a normal `PathElement`, so it animates, morphs
  (v0.43), and exports everywhere.

## How it works

The geometry is a pure, unit-tested helper (`src/editor/utils/pen-path.ts`):
`buildPenPath` turns nodes into `M … L/C … [Z]`, `localizePenPath` fits them into
an element box, `mirrorHandle` makes symmetric drag handles. The preview tracks
nodes in stage coordinates (mapped via the canvas rect, so it's correct at any
zoom) and, on finish, adds the localised path.
