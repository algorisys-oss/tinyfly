# v0.63.0

**Release Date:** 2026-09-14

This release closes the remaining GSAP gaps: native elastic, bounce, back and steps
eases; `live.utils` with seeded random values and `repeatRefresh`; tween keyframes;
grid staggers; rotation dragging; scroll batches and scroll-to; horizontal scrollers.
It also adds hooks for React, Vue, Svelte and Solid, makes shape morphing faster, and
is the first release published to npm.

## Added

### Native elastic, bounce, back and steps eases

The engine has parametric eases, serialized as one small keyframe and evaluated
exactly when played:

```json
{ "type": "elastic", "mode": "out", "amplitude": 1, "period": 0.3 }
{ "type": "steps", "count": 5, "position": "end" }
```

- GSAP names map to them with their parameters: `elastic.out(1.2, 0.4)`,
  `bounce.in`, `back.out(3)`, and `steps(n)` as GSAP's n + 1 levels.
- The studio's easing picker has them, with mode, amplitude, period, overshoot,
  steps and jump position.
- CSS and Lottie exports sample them into keyframes. `bakeEases: true` still
  samples them at build time, for older players.

### Utilities, random values and `repeatRefresh`

```js
const { mapRange, interpolate, wrap, snap, random, distribute, pipe } = live.utils

live.to('.dot', { x: 'random(-200, 200, 10)', scale: distribute({ base: 0.5, amount: 1, from: 'center' }) })
live.timeline({ repeat: -1, repeatRefresh: true }).to('.star', { x: 'random(-300, 300)' })
```

- **`live.utils`:** `clamp`, `mapRange`, `normalize`, `interpolate`, `wrap`,
  `wrapYoyo`, `snap`, `random`, `shuffle`, `distribute`, `pipe`, `splitColor`,
  `getUnit` and `seed`.
- **Seeded randomness:** a page builds the same "random" layout every load, and a
  replay is identical.
- **Tween values:** `"random(…)"` strings are drawn per element, and function values
  receive `(index, target, targets)`.
- **`repeatRefresh`** draws function and random values again on every loop.
- **`live.getProperty(target, property)`** returns the value tinyfly last applied.

### Tween keyframes and grid staggers

```js
live.to('.ball', { keyframes: [{ x: 100, duration: 0.4 }, { y: 50, ease: 'bounce.out' }] })
live.to('.ball', { duration: 2, keyframes: { '0%': { x: 0 }, '50%': { x: 200 }, '100%': { x: 100 } } })
live.to('.cell', { scale: 0, stagger: { grid: [5, 8], from: 'center', amount: 1.2, ease: 'power2.in' } })
```

- **Keyframes:** the array, percentage and value-array forms are all supported, with
  `easeEach`. With `stagger`, each target plays the whole sequence.
- **Staggers:** `grid` (or `'auto'`, read from layout), `from: 'random'` or `[x, y]`,
  `axis` and `ease`. The result is stored as explicit per-target `stagger.offsets`,
  a new engine field, so the JSON stays plain.

### Dragging and scrolling

- **Rotation dragging:** `live.draggable('.knob', { type: 'rotation' })` turns an
  element about its centre. It keeps turning past ±180°, and supports
  `{ minRotation, maxRotation }`, snapping in degrees and inertia spins.
- **Batches:** `live.scrollBatch(targets, { interval, batchMax, onEnter })` gives one
  trigger per element, with elements that cross together delivered in one callback.
- **Scroll-to:** `live.scrollTo(offset | element | selector | 'max', vars)` and
  `live.to(window, { scrollTo })`. The reader's own scrolling stops it.
- **Scroll triggers:** `pinSpacing: false` lets later content scroll up under the pin,
  and `horizontal: true` supports sideways scrollers.

### Framework hooks

```jsx
import { useTinyfly } from 'tinyfly/react'
const root = useRef(null)
const { contextSafe } = useTinyfly((live) => live.from('.title', { y: 40, opacity: 0 }), { scope: root })
```

- **Entry points:** `tinyfly/react` (`useTinyfly` with scope, dependencies and
  `contextSafe`), `tinyfly/vue` (a composable with scope and `watch`),
  `tinyfly/svelte` (an action) and `tinyfly/solid` (`createTinyfly`).
- **Cleanup:** each runs its setup in a `live.context()` scoped to the component, and
  reverts everything on unmount.
- **Size:** each is under 1 kB. The frameworks are optional peer dependencies.

### npm

- **Install:** `npm install tinyfly`. Every entry point ships with TypeScript
  declarations.
- **Releases:** publishing to npm is now part of every release.

## Changed

### Faster shape morphing

A morph plan is simplified once, when it's worked out: points that lie within 0.2
units of a straight line in both shapes are dropped. Corners and tight curves are
kept. Plans are also looked up without building a long string key every frame. A
10-path morph benchmark went from 43.5 to 24.4 ms of script per second of animation.

## Fixed

- **Elastic, bounce and steps played linear on `live`.** Sampling was opt-in and
  nothing turned it on, so the motion was straight with only a warning. These eases
  now play their real curves.

## Upgrade Notes

- **Timing:** `elastic.*`, `bounce.*` and `steps(n)` on `live` now play their real
  curves instead of linear. `steps(n)` follows GSAP (n + 1 levels), so its step
  timing changes slightly.
- **Stored JSON:** a plain `back.*` keeps its cubic-bezier. Only `back.*` with an
  overshoot argument becomes parametric.
- **Reading definitions:** tools that read timeline JSON should accept the new
  `easing` objects and `stagger.offsets`, or run `expandParametricEasings` first.
