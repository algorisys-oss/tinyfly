# v0.18.0

**Release Date:** 2026-07-22

Small release that lets you **name your export**, plus a **BETA** badge in the
editor header.

## Highlights

- **Filename field in the Export dialog.** Every format — CSS, Lottie, GIF, WebP,
  MP4 — now downloads under a name you choose, with the extension shown beside
  the field so you always know what you'll get.
- **Sensible default.** The field pre-fills from the **project name**, so a
  project called "My Promo Video!" exports as `my-promo-video.mp4` instead of
  `scene-1.mp4`.
- **Names are sanitized, not rejected.** Type whatever reads well;
  path separators, reserved characters and awkward punctuation are stripped, and
  a "Saved as …" line previews the real filename whenever it differs from what
  you typed.
- **BETA badge** next to the wordmark in the editor header.

## Why this was needed

Before this release the download name came from `Timeline.name`, which is set
**once when the timeline is created** and never updated afterwards. That meant:

- A fresh project exported as `scene-1.mp4` (the default scene's name).
- Renaming the scene or the project did **not** change it — `renameScene` only
  touches the scene, and the timeline name was already serialized.
- `Timeline.name` is `readonly` in the engine, so nothing in the UI could change
  it after the fact.
- CSS and Lottie ignored it entirely, always downloading `animation.css` /
  `animation.json`.

Renaming the file after download was the only workaround. The new field solves
this in the editor layer and leaves `Timeline.name` readonly, so the engine's
determinism guarantee is untouched.

## Added

- `slugifyFilename(name, fallback)` — filesystem-safe slug helper
  (`src/editor/utils/filename.ts`).
- Export dialog: **Filename** field with live extension suffix, a sanitized
  "Saved as …" preview, and a **Reset** button that returns to the project name.
- `.editor-beta-tag` badge in the editor header.

## Changed

- CSS and Lottie downloads now honour the filename field instead of the hardcoded
  `animation.css` / `animation.json`.

### Sanitization rules

A whitelist rather than a blacklist — anything that is not a unicode letter,
digit, hyphen, dot, space, or underscore is dropped:

| Input | Filename |
|-------|----------|
| `My Promo Video!` | `my-promo-video` |
| `report: q1/q2 <draft>` | `report-q1q2-draft` |
| `../../etc/passwd` | `etcpasswd` |
| `promo v1.2` | `promo-v1.2` |
| `Café 2024` | `café-2024` |
| `CON` (Windows device name) | `animation` |
| `` (empty) | `animation` |

Names are capped at 100 characters with no trailing hyphen.

### Test Coverage

- 604 tests passing (+14: the filename sanitizer — spacing, punctuation, path
  separators, Windows reserved device names, unicode, length capping, and the
  empty/fallback paths).

### Verified in a real browser

Driven through the Chrome DevTools Protocol against the running editor:

- The field defaults to `my-promo-video` for a project named "My Promo Video!".
- The extension suffix tracks the selected format: `.css`, `.json`, `.gif`,
  `.webp`, `.mp4`.
- Typing `Final Cut: v2/final` previews **Saved as final-cut-v2final.gif**.
- The BETA badge renders in the header.
