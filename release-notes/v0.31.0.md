# v0.31.0

**Release Date:** 2026-07-22

A tidier top toolbar — one row, fewer buttons, and the two Export buttons merged.

## Highlights

- **"More" overflow menu.** Secondary actions — **Import JSON**, **Export JSON**,
  **Embed**, **Examples Gallery**, **Docs**, **Keyboard Shortcuts** — now live in a
  single **⋯ More** dropdown. The toolbar keeps only the primary actions
  (New, AI, My Animations, Samples, Export), so it fits one row and stops wrapping
  to a second row on narrow windows.
- **One Export button.** The confusing pair (**Export** = JSON and **Export As** =
  media/code) is merged: the toolbar **Export** button now opens the format dialog
  (GIF / WebP / MP4 / CSS / Lottie), and plain **Export JSON** moved into the More
  menu next to **Import JSON**.

## Technical Details

| File | Description |
|------|-------------|
| `src/editor/components/toolbar.tsx` | Primary buttons + More dropdown (outside-click close); export consolidation |
| `src/editor/components/toolbar.css` | More-menu styles |

No engine or test changes — 645 tests passing.
