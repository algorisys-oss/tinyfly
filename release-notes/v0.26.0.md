# v0.26.0

**Release Date:** 2026-07-22

**Symbols now render everywhere** — instances flatten into raster export, embeds,
thumbnails, and the Canvas preview. What you build with symbols also ships in
your output.

## Highlights

- **Symbols in export.** GIF / WebP / MP4 export now includes symbol instances —
  each is flattened into its shapes (translated, scaled, rotated, opacity-
  multiplied into the instance box). Previously instances were silently skipped.
- **Symbols in embeds.** Embed code (single scene and full sequence) expands
  instances into ordinary elements, so embedded animations show them.
- **Symbols in thumbnails.** Gallery cards, scene tabs and Library items render
  instances in their thumbnails.
- **Canvas preview.** The Canvas renderer draws instances too (static), matching
  the DOM preview's content.

## How it works

A new `expandSymbolInstances(elements, getSymbol)` util replaces every `symbol`
element with transformed copies of its symbol's contents (nested symbols expand
recursively, with a depth guard). Because the result is a flat list of ordinary
elements, all the existing render/export/embed paths — none of which understand
symbols — handle instances for free. This is a **static** expansion (poster
frame); a symbol's nested timeline animation is not yet baked into export.

## Added

- `src/editor/utils/expand-symbols.ts` — `expandSymbolInstances` + `hasSymbolInstances`.
- Instance flattening wired into: raster export (`export-dialog`), embeds
  (`embed-dialog` + `exportSequence`), thumbnails (`scene-thumbnail` +
  callers), and the Canvas preview (`preview-panel`).
