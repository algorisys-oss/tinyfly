# v0.28.3

**Release Date:** 2026-07-22

The timeline **Expand** button now truly maximizes — full timeline view on any
window height.

## Improved

- **Expand = maximize.** Clicking Expand in the timeline header now **hides the
  preview** and gives the entire centre area to the timeline (playback controls
  stay). On short windows the previous version still squeezed the track rows;
  now one click gives you the whole timeline. Click again (or the same button) to
  restore the preview.

## Technical Details

| File | Description |
|------|-------------|
| `src/editor/editor.tsx` | Expand toggles a `.timeline-maximized` layout instead of nudging height |
| `src/editor/editor.css` | Maximized: hide preview + splitter, timeline fills the centre |

No engine or test changes — 645 tests passing.
