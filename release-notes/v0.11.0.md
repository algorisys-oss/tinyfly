# v0.11.0

**Release Date:** 2026-07-11

Minor release that adds a **device-frame preset** — one click stamps a phone,
landscape, or tablet mockup with a rounded video "screen", sized to the canvas —
so building an app-promo goes from hand-compositing to a single click. Also
restyles the status-bar version as an obvious reload button.

## Highlights

- **Device-frame preset** - Add a **Phone**, **Landscape**, or **Tablet** mockup
  (rounded body + rounded video screen + camera/notch) from the Elements panel;
  it's sized to fit the current canvas and multi-selected so you can move or
  group it as one. Drop a screen-recording into the screen's `src`.
- **Rounded video corners** - The Video element gained a `borderRadius`, so a
  screen (or any video) can have rounded corners in the preview and in exports.
- **Reload button** - The version chip in the status bar is now a clear pill with
  a ⟳ icon that spins on hover; clicking it hard-reloads (cache-busted) as before.

## Added

- **`addDeviceFrame(variant, …)`** on the scene store - Stamps a body (rect),
  screen (video, `object-fit: cover`, rounded), and camera (pill notch for a
  portrait phone, a dot otherwise) as top-level elements, then multi-selects
  them. Sizing derives from the canvas and scales to fit any aspect ratio.
- **Device presets in the Elements panel** - A "Presets · Device" row with
  **Phone / Landscape / Tablet** buttons.
- **`borderRadius` on `VideoElement`** - Applied in the DOM preview and in
  exported HTML.

## Changed

- The status-bar version is now a real `<button>` styled as a pill (icon + label,
  hover glow + icon spin, focus ring) instead of plain blue text.
