# v0.106.0

**Release Date:** 2026-10-12

Open any catalog example in a full page while keeping the gallery and its code
available in the original tab.

## Added

- **Open full page** action on every live, timeline and editable example card,
  including the individual example pages.
- Shareable `/examples/<id>/full` URLs: animations play immediately with their
  controls and independent scrolling in a full-viewport standalone player.
- A friendly missing-example view with a link back to the catalog.

## Validation

- Chromium checks cover real new-tab navigation, viewport dimensions,
  animation, manga controls, timeline and editable scenes, mobile fit and
  missing examples, without browser errors.
- The player reuses the existing standalone HTML builders and their tests.

## Upgrade Notes

- Full-page players use the same release-pinned bundles as Copy code exports.
- The public manga, face, hair and stick-figure arm APIs added in 0.105.0 remain
  available; this release adds the website preview action.
