# v0.30.0

**Release Date:** 2026-07-22

Collapsible left-sidebar sections and a timeline resizer that actually resizes.

## Highlights

- **Collapsible panels.** Each left-sidebar section — **Elements**, **Tracks**,
  **Library** — now has a chevron in its header. Click to collapse it to just the
  header, freeing that space for the sections you're using. State persists across
  sessions.
- **Timeline resizer actually resizes.** On short windows the splitter appeared to
  do nothing because the preview was pinned at its minimum height with no room to
  give. The preview minimum is smaller now, so dragging the splitter has real
  range; the grip is also easier to grab (wider hit area, highlights on hover).

## Technical Details

| File | Description |
|------|-------------|
| `src/editor/utils/use-collapsed.ts` | Persisted per-panel collapse flag |
| `src/editor/components/{element,track,library}-panel.tsx` | Chevron toggle + collapsed class |
| `src/editor/components/element-panel.css` | Shared collapse styles |
| `src/editor/editor.css` | Collapsed panels shrink to header; preview min-height 120→80; grabbier splitter |

No engine or test changes — 645 tests passing.
