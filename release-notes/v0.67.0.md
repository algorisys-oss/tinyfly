# v0.67.0

**Release Date:** 2026-09-14

The studio can export an Animation Document: the scene's elements and tracks in one file.

## Added

### More → Export Animation Document

- **What it does:** downloads `<name>.animation.json` with the scene's elements, tracks and
  canvas, plus the animation's name, playback options other than duration (`loop`, `speed`,
  `markers`...) and captions.
- **Why:** **Export JSON** writes the timeline alone. Its tracks name their targets but say
  nothing about what to draw, so another app could not rebuild the animation from it.
  YappyDraw's **Import tinyfly animation…** now reads this file, creates the shapes and plays
  the animation on them.
- **Format:** the Animation Document described in `docs/file-format.md`. Tracks are the
  editor's tracks unchanged, so springs, staggers and scheduling fields are kept for readers
  that run the engine, and element ids are kept because groups refer to their children by id.
