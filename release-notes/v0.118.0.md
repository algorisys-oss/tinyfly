# v0.118.0 — Maths animations: discrete maths

Released: 2026-10-16

`@algorisys/tinyfly/math` adds discrete maths: graph searches you can step
through, recursion trees, Venn diagrams of any set expression, and clock
arithmetic.

## Added

- `graph` item:
  - Nodes and edges as JSON, undirected or directed, weighted or not.
  - `search: { kind: 'bfs' | 'dfs' | 'dijkstra', start }` is shown by `step`.
    Finished nodes, the queue, stack or open set, and the edges each node was
    reached by are all drawn; a fractional step draws the edge being crossed.
  - `frontier` shows the queue or stack as a row; Dijkstra shows each node's
    distance.
  - `tree: { root }` lays nodes out top down.
  - Derived numbers: `ID.visited`, `ID.steps`, `ID.d.NODE`.
- `venn` item: two or three sets with a region shaded from a set expression:
  `A | B`, `A & B`, `A - B`, `A ^ B`, `A'`, with brackets, or `∪ ∩ ∖ △ ¬`.
- `clock` item: clock arithmetic, with the hand at `value` mod `modulus`.
  Derived numbers: `ID.hour`, `ID.turns`.
- Graph searches, tree layout and set expressions as data: `searchEvents`,
  `treeLayout`, `parseSetExpression`, `regionCells`.
- Presets: `graphSearchFigure`, `shortestPathFigure`, `recursionTreeFigure`
  (naive Fibonacci's calls, in call order), `vennFigure`, `clockFigure`.
- Display-list clipping (`clip` on line shapes, inside or outside a polygon).
  Canvas and SVG both support it, and SVG clip ids are named from their
  geometry so the output is deterministic.
- TeX: `\binom`, `\triangle`, `\oplus`, `\otimes`, `\varnothing` and more set
  and logic symbols.
- Gallery: Graph Search, Recursion Tree, Set Operations, Clock Arithmetic.
- Videos: `graph-search-short.mjs` (9:16) and `de-morgan-explainer.mjs`
  (16:9).

## Changed

- Operators and symbols are drawn in a maths-symbol font stack
  (`MATH_SYMBOL_FONT`) that falls back to DejaVu. Node renders now show ∪ △ ∈
  and similar symbols even where the text serif lacks them.
- Hyphens, apostrophes and primes have their own widths, so `\text{…}` and f′
  set tighter.

## Validation

- Breadth-first and depth-first search orders and frontiers, Dijkstra's
  distances and paths, directed reachability, and tree layout are tested.
- Set-expression precedence, aliases and errors are tested, and De Morgan's
  two sides give the same cells.
- Venn regions are checked in canvas and in deterministic SVG; clock residues
  are checked, negatives included.
- All gallery demos checked at desktop and phone widths; video stills
  reviewed.
