# v0.71.0

**Release Date:** 2026-09-27

Video from code. Write a scene in JavaScript and render it to an MP4 without a browser, the
way a Cairo or Processing script does, with tinyfly's timeline, easing and JSON on top.

```bash
npm install @algorisys/tinyfly @napi-rs/canvas   # plus ffmpeg on the PATH
npx tinyfly video scene.mjs -o scene.mp4 --srt scene.srt
npx tinyfly video scene.mjs --stills stills/
```

## Added

### `tinyfly video` and `@algorisys/tinyfly/headless`

- **Render to MP4 in Node:** every frame is drawn from scratch at an exact time
  (`frame / fps`), piped as raw RGBA to ffmpeg and encoded as H.264, with an optional
  soundtrack muxed in. The same scene always renders the same pixels.
- **Stills:** `--stills <dir>` writes one PNG from the middle of each marker's step, for
  checking layout without encoding a video.
- **Options:** `-o`, `--scale` (quick previews), `--fps`, `--crf`, `--no-audio`, `--srt`,
  `--vtt`.
- **A scene** default-exports `{ width, height, fps, duration, timeline, targets,
  background, draw, audio, fonts, captions }`. Draw with timeline targets, with a
  `draw(ctx, { time })` function (Cairo-style), or both; `background` may be a function
  that draws under the targets.
- **From a script:** `renderVideo()`, `renderStills()`, and `FrameRenderer`, which draws a
  scene onto any 2D context (including a browser canvas).

### Custom canvas targets

- `type: 'custom'` with a `draw(ctx, target, time)` function: code draws it in local
  coordinates, while the `CanvasAdapter` applies position, opacity, transforms and filters.
- Tracks write into the values the target declares in `props`, so a character's pose is
  keyframe data while its drawing is code. Works in the browser as well as headless.

### Narration timing

- `planNarration(scenes, { lead, gap, tail })` lays spoken lines out from their clip
  lengths into cues (`start`, `end`, `text`), scene spans and a total duration.
- `narrationMarkers(plan)` makes one labelled marker per line; `narrationSceneAt(plan, t)`
  finds the scene playing.

### Captions

- `toSRT(cues)` and `toWebVTT(cues)`, plus `captionCuesFromTimeline(definition)` to make
  cues from a timeline's markers and captions. In `@algorisys/tinyfly/export` and
  `@algorisys/tinyfly/headless`.

### Examples and docs

- **Guide:** [Rendering Video from Code](../docs/video-rendering.md), including a table for
  porting Cairo scripts.
- **Scenes:** `examples/headless-video/` has a narrated stick figure, a bar chart made only
  of timeline targets, and a pure immediate-mode sketch. Unit tests draw every still of
  every scene.
- **Gallery:** a new **Video** category with a live **Narrated Scene** card.
- `docs/examples.md` has a "Video from Code" section; the API reference covers custom
  targets, captions and the headless entry.

## Changed

- The copied-page test for gallery demos now provides the engine on the `tinyfly`
  global, as the browser bundle does.
- The Vite plugin that keeps the engine out of add-on bundles moved to
  `vite-externalise-engine-plugin.ts`. Exporters are now bundled into whichever entry
  imports them; no existing entry's output changes.
