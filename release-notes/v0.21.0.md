# v0.21.0

**Release Date:** 2026-07-22

Timeline **zoom & scroll**, a friendlier **keyframe-add**, and a **beginner-first
documentation** overhaul.

## Highlights

- **Timeline zoom & scroll.** The timeline (both Dope Sheet and Curves) can now
  be zoomed and panned:
  - **− / 100% / +** control at the top-right; click the percentage to reset.
  - **Ctrl/⌘ + scroll** zooms toward the cursor.
  - A **scrollbar** under the timeline, plus **Shift + scroll** / horizontal
    swipe to pan.
  - Both views share the same zoom/scroll, so switching keeps your place.
- **Smarter double-click-to-add.** Double-clicking a Dope Sheet track to add a
  keyframe now seeds it with the track's **held value** at that time instead of
  `0`, so the value no longer jumps.
- **Documentation for beginners.** [Getting Started](../docs/getting-started.md)
  is rewritten as a genuine, no-jargon walkthrough (open the editor → load a
  sample → build one from scratch → ease → save → export), with a labelled tour
  of the UI. The [Editor Guide](../docs/editor-guide.md) is updated throughout for
  the current UI — Save button & auto-save, **My Animations** gallery, collapsible
  panels, the **Dope Sheet vs Curves** views, and zoom/scroll.

## Added

- Shared zoom controls, `Ctrl/⌘+wheel` zoom-to-cursor, wheel/shift panning, and a
  draggable horizontal scrollbar in `TimelinePanel`.

## Changed

- Dope Sheet double-click add-keyframe holds the track's current value (and now
  accounts for horizontal scroll when computing the time).
- `getting-started.md` rewritten; `editor-guide.md` layout, toolbar, timeline and
  project-management sections updated for the current editor.

### How zoom/scroll works

Both timeline views already positioned content from the store's `zoom` and
`scrollPosition`; this release simply adds the UI to change them (plus bounds
clamping from the measured viewport width). The engine is untouched.

### Test Coverage

- 627 tests passing (no change — this release is UI + docs; the curve/keyframe
  logic already carried its unit tests).
