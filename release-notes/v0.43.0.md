# v0.43.0

**Release Date:** 2026-07-22

**Shape morphing** — tween one shape into another.

## Highlights

- **🌀 Shape Morph.** Select a path (polygon, star, or any path), pick a target
  shape in **Properties → Shape Morph**, and click **Create shape morph →**. A
  `d` track tweens the shape across the timeline. Press Play to watch it morph.
- **Engine-level & deterministic.** The engine interpolates path `d` strings
  natively — no DOM required — so morphs play the same in the editor, embeds,
  workers, and exports.
- **Renders everywhere.** DOM, SVG, and Canvas previews, raster export
  (GIF/WebP/MP4), and embeds all animate the morph.

## How it works

`getInterpolator` now detects SVG path data and routes it to a new path morph
(`src/engine/path/path-morph.ts`): both paths are sampled uniformly along their
length with `getPointAtProgress` and the points are blended by progress, so any
two shapes morph smoothly. Each renderer applies the animated `d`: the DOM/embeds
adapter drives the child `<path>`, the SVG adapter sets the `d` attribute, and the
Canvas adapter rebuilds a `Path2D` per frame.
