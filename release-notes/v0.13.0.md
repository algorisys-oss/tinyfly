# v0.13.0

**Release Date:** 2026-07-11

Minor release that makes **undo/redo proper**: history now covers scene elements
as well as the timeline, so a single Ctrl+Z reverses whatever you changed last.

## Highlights

- **Unified undo/redo** - Previously undo only tracked the timeline
  (tracks/keyframes); element operations were not undoable. Now every history
  entry is a full `{ timeline, elements }` snapshot, so **Ctrl+Z / Ctrl+Shift+Z**
  reverse element **and** keyframe changes alike:
  - Add / delete / duplicate elements
  - Move (drag), resize, rotate, path-point edits
  - Group / ungroup, layer reorder
  - The device-frame preset (as one step)
  - Property-panel edits and nudges
  - Track / keyframe edits (as before)
- **Gestures are one step** - A drag, resize, or rotate collapses into a single
  undo step (a click that doesn't move records nothing).

## Changed

- The editor store's history is now a unified `{ timeline, elements }` snapshot
  stack with a correct undo/redo model (live-capture at each boundary). The
  scene store snapshots through an injected hook before each mutation; the editor
  wires the two together and reads/writes elements via `attachScene`.
- Continuous preview gestures wrap their updates in `beginInteraction` /
  `endInteraction` so they don't flood the history.
- History is still cleared at scene/project boundaries (scene switch, new
  project, import, sample load), so undo never crosses scenes.

## Fixed

- Element edits (add, delete, move, resize, group, device, property changes) are
  now undoable — previously they were silently lost by undo.

## Technical Details

### Changed Files

| File | Description |
|------|-------------|
| `src/editor/stores/editor-store.ts` | Unified `{timeline, elements}` history + `attachScene`, `pushHistory`; correct undo/redo model |

| `src/editor/components/preview-panel.tsx` | Wrap drag/resize/rotate/path-point gestures in begin/endInteraction |
| `src/editor/editor.tsx` | Wire the scene store to the editor's history |

### Test Coverage

- 531 tests passing (+6 undo integration: add/undo/redo, property-edit undo,

  timeline-track undo). Verified live: adding elements, dragging, and Ctrl+Z/
  Ctrl+Shift+Z behave correctly, with a drag reverting in a single step.
