# v0.86.0

**Release Date:** 2026-10-05

A WebGL2 renderer for 3D scenes. The same scene and the same resolved frame,
drawn by the GPU: a depth buffer, so shapes that cut through each other and
huge floors draw right; light per pixel, so smooth shapes are smooth and toon
bands, spot pools and fog have clean edges; ink outlines and see-through
meshes. This is milestone 3 of the [3D plan](../docs/3d-support-plan.md).

## Added

- **`@algorisys/tinyfly/scene-3d/webgl`** (and `tinyfly-scene-3d-webgl.iife.js`):
  `new WebGL2Renderer(gl, { overlay? })`, `render(frame)`, `destroy()`. Works
  with `Scene3DAdapter`, on a page or in a Worker (OffscreenCanvas).
  - The Canvas 2D renderer's light model per pixel: unlit, flat, smooth and
    toon shading; ambient, directional, point and spot lights with ranges
    and cones (up to 8); fog.
  - Ink outlines by the inverted hull (silhouettes).
  - See-through meshes after the opaque ones, far to near.
  - Objects drawn whole (characters in their pen look, shadows) on a 2D
    overlay canvas; solid characters are meshes and sort properly.
- **`ResolvedScene3D.meshes`**: every visible mesh in world space (including
  the ones added kinds place), for renderers with a depth buffer.
- The **3D Scene: Orbiting Camera** demo switches between Canvas 2D and WebGL2.
- e2e check `scene-3d-webgl`: in Chromium, Firefox and WebKit the shaders
  compile, silhouettes match the Canvas 2D renderer's (about 97%), and the
  depth buffer is right.
