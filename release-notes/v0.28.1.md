# v0.28.1

**Release Date:** 2026-07-22

Timeline breathing room — the bottom pane no longer feels cramped.

## Fixed / Improved

- **Taller, resizable timeline.** The default height is bigger (260px) and the
  splitter now drags up to ~80% of the window (was capped at 560px), so you can
  see many more track rows.
- **One-click Expand.** A new button in the timeline header flips to a tall,
  timeline-focused layout and back (double-clicking the splitter still resets).
- **Remembers your size.** The chosen timeline height persists across sessions.
- Track list still scrolls vertically for long track lists.

## Technical Details

| File | Description |
|------|-------------|
| `src/editor/editor.tsx` | Persisted height, viewport-relative resize cap, expand toggle |
| `src/editor/components/timeline-panel.tsx` / `.css` | Expand button in the header |

No engine or test changes — 645 tests passing.
