# v0.70.1

**Release Date:** 2026-09-15

Full screen on a phone held sideways now gives the drawing the room.

## Fixed

### Full screen on short landscape screens

- **What was wrong:** v0.70.0 stacked the controls, scenario choices and captions under
  the drawing. On an 844×390 screen they took most of the height, and a 720×420 diagram
  was drawn only about 233px wide, smaller than in the page.
- **Now:** on a landscape screen up to 520px tall, the drawing fills the left of the
  screen and the controls and captions sit in a column on the right. The same diagram is
  drawn 529px wide.
- **Found by:** measuring every figure of the teachyourselfcoding.com System Design lessons
  full screen in desktop Chromium, and in WebKit at iPhone sizes in portrait and landscape.

## Changed

- **e2e:** the native fullscreen check now leaves full screen the way the browser does
  (`document.exitFullscreen()`), and checks the controls follow. Before, it pressed Esc and
  quietly clicked the button if that didn't work. Automated key presses never reach the
  browser's own Esc handling, so the old check was proving the button, not Esc.

## Technical Details

| File | Description |
|------|-------------|
| `src/embed/controls.ts` | Grid layout for `.tf-fullscreen` under `(orientation: landscape) and (max-height: 520px)` |
| `e2e/checks/embed.mjs` | Short-landscape layout measured; native exit check made honest |
