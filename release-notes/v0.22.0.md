# v0.22.0

**Release Date:** 2026-07-22

The timeline follow-ups land: **box-select**, a **curve Overlay** mode, and
**per-scene thumbnails**.

## Highlights

- **Box (rubber-band) select.** Drag across empty space in either timeline view
  to select every keyframe inside the rectangle — the **Dope Sheet** (diamonds)
  and the **Curves** view (points). Works alongside Ctrl/⌘-click multi-select;
  then Delete / copy / paste the group.
- **Curves: Lanes vs Overlay.** A new toggle at the top-left of the Curves view:
  - **Lanes** — each track in its own editable row (the default).
  - **Overlay** — every numeric curve drawn on **one shared axis**, each in its
    own colour with a legend, so you can compare timing and shape across tracks
    at a glance. Click a point to select it; switch back to Lanes to edit.
- **Per-scene thumbnails.** Each tab in the **Scene Bar** now shows a small live
  thumbnail of that scene, so multi-scene projects are easy to navigate. The
  active scene's thumbnail stays current as you edit.

## Added

- Rubber-band selection in `timeline-view.tsx` (Dope Sheet) and `curve-view.tsx`
  (Curves), hit-testing keyframes/points against the drag rectangle.
- `Lanes | Overlay` mode in the Curves view, with a colour palette + legend and a
  height-parameterized curve renderer.
- Scene-tab thumbnail generation/display in `scene-bar.tsx`; the editor now stores
  each captured thumbnail under both the project id (gallery) and the active scene
  id (scene tab).

## Technical Details

| File | Description |
|------|-------------|
| `src/editor/components/timeline-view.tsx` / `.css` | Dope Sheet box-select |
| `src/editor/components/curve-view.tsx` / `.css` | Curves box-select + Overlay mode |
| `src/editor/components/scene-bar.tsx` / `.css` | Per-scene tab thumbnails |
| `src/editor/editor.tsx` | Thumbnail captured under project id **and** active scene id |

### Notes

- Box-select uses the existing `selectKeyframes(refs)` store action — no engine
  changes; the views hit-test against the same `zoom`/`scrollPosition` geometry
  they render with.
- Overlay is a comparison view: points are selectable but editing (drag/handles)
  stays in Lanes mode to keep interactions unambiguous.
- Scene thumbnails render once per scene from its stored elements; the active
  scene is kept fresh by the editor's debounced capture.

### Test Coverage

- 627 tests passing (unchanged — this release is editor-layer UI over existing,
  already-tested store actions and the curve-math helpers).
