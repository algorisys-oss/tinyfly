# v0.58.0

**Release Date:** 2026-09-14

An interactive course at `/learn`, starting with the GSAP-style API, and a
shareable page for every example.

## Added

### Learn tinyfly (`/learn`)

A hands-on course inside the app.

- **The course map** lists modules and lessons with progress dots, Start /
  Continue, reset progress, and the modules still to come.
- **Each step** is a short explanation with hints revealed one at a time, a code
  editor, a live preview you can scrub or replay, and checks:
  - the code runs 400ms after you stop typing;
  - drafts are saved;
  - Reset, Show solution, and Back / Next (Skip until the step passes);
  - on phones the three panes stack.
- **Checks read what the code built, not the screen.** They look at the compiled
  timeline JSON, the tracks on an element, and the value of a property at a given
  time. The result doesn't depend on how far playback has got, and each failure
  says what is still wrong.
- **Module 1, the GSAP-style API** (3 lessons, 10 steps):
  - **Your first tween:** `to`, duration and ease, `from`, `fromTo`.
  - **Many elements:** selectors, `stagger`, a stagger from the centre.
  - **Timelines:** sequencing, the position parameter, repeat with yoyo.
- **Links:** Learn is reachable from the landing page nav and footer, and from the
  editor's More menu.

Lessons are plain data (`src/learn/modules/`), so adding one needs no change to
the runtime.

### A page for every example (`/examples/<id>`)

- **Opening:** click a card's title, or visit the address directly.
- **On the page:** the example plays without hovering. It offers **Copy link** and
  lists more from its category.
- **Sharing:** the browser tab shows the example's name, and a mistyped id says
  so.
- **Landing gallery:** its cards now link straight to these pages.

## Technical Details

| File | Description |
|------|-------------|
| `src/learn/types.ts`, `course.ts` | Course data model and step lookup |
| `src/learn/runner.ts` | Runs a step's code in a scoped preview; check context |
| `src/learn/checks.ts` | Check builders with learner-facing messages |
| `src/learn/modules/gsap-api.ts` | Module 1 |
| `src/learn/learn-page.tsx`, `progress.ts` | Course map, step page, local progress and drafts |
| `src/examples/example-page.tsx` | Per-example page; `ExampleCard` shared with the grid |

### Test Coverage

- **Unit:** 1,799 tests passing. The course's gate checks that every step's
  solution passes its checks and no starter already does.
- **Cross-browser:** 161 checks passing in Chromium 150, Firefox 153 and WebKit 26.5.
  MP4 export in Linux WebKit is reported as a note. New checks:
  - **`learn`:** every step completes through its solution, progress persists,
    and a step fits a phone-width screen.
  - **`example-pages`:** examples open directly and play without hover, grid
    titles link to their pages, and unknown ids are handled.
