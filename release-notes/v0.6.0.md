# v0.6.0

**Release Date:** 2026-07-08

Minor release focused on **distribution and reach**: the engine is now a
publishable npm package, the player ships as a CDN-ready bundle, audio/video can
be locked to the timeline, and the shine sweep works on every renderer.

## Highlights

- **NPM engine package** - The framework-agnostic engine builds to an ESM + UMD
  library with type declarations and a proper `exports` map
- **CDN player bundle** - A self-contained IIFE/UMD/ESM player build, usable from
  a single `<script>` tag (global `tinyfly`)
- **Audio/video sync** - `MediaSync` / `player.attachMedia()` keeps an audio or
  video element locked to the timeline clock
- **Shine sweep everywhere** - The text shine now renders on DOM, SVG, and Canvas

## Added

- **Engine library build** - `vite.config.engine.ts` + `npm run build:engine`
  emit `lib/engine/tinyfly-engine.js` (ESM) and `.umd.cjs`. `tsconfig.lib.json` +
  `npm run build:types` emit declarations to `lib/types`. `npm run build:libs`
  runs the full set.
- **Package entry points** - `main` / `module` / `types` and an `exports` map:
  `import { Timeline } from 'tinyfly'` (engine) and
  `import { TinyflyPlayer, MediaSync } from 'tinyfly/player'`.
- **Audio/video sync** - `MediaSync` (pure, DOM-free, structural media interface)
  plus `player.attachMedia(media, { offset, driftTolerance })` and
  `player.detachMedia()`. The timeline stays the clock; the media follows
  play/pause/seek/rate and drift is corrected as it plays.
  (`src/player/media-sync.ts`)
- **Shine on SVG & Canvas** - A shared `shineStops()` builds the highlight
  gradient; Canvas fills text with a linear gradient (glyph-clipped by
  `fillText`), SVG injects a `<linearGradient>` into `<defs>`.
  (`src/adapters/shine-utils.ts`)

## Changed

- **Library outputs** now live in `lib/` (outside the app's `dist/`), so the app
  build no longer wipes the published bundles.
- The `Shine Sweep` preset no longer notes a renderer restriction — it works on
  all three.

## Distribution

```bash
npm run build:libs   # -> lib/engine, lib/player, lib/types
```

```js
import { Timeline, createTrack } from 'tinyfly'          // engine
import { TinyflyPlayer, MediaSync } from 'tinyfly/player' // player + sync
```

```html
<script src="https://unpkg.com/tinyfly/lib/player/tinyfly-player.iife.js"></script>
<script>new tinyfly.TinyflyPlayer('#stage').load('a.json').then(p => p.play())</script>
```

## Upgrade Notes

Upgrade from v0.5.0:

1. No breaking changes — all additions are backwards-compatible
2. Build the libraries with `npm run build:libs` before publishing/embedding
3. `MediaSync` and the engine/player entry points are new, optional APIs
