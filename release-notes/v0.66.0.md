# v0.66.0

**Release Date:** 2026-09-14

One script covers everything: `tinyfly.iife.js` now includes teaching embeds.

## Added

### Teaching embeds in the all-in-one bundle

```html
<script src="https://cdn.jsdelivr.net/gh/algorisys-oss/tinyfly@v0.66.0/cdn/tinyfly.iife.js" data-tinyfly-auto></script>
<script>tinyfly.to('.box', { x: 200 })</script>
```

- **What's included:** step controls (`createControls`), declarative mounting
  (`mountAll`, `mount`, `unmount`), and automatic mounting of every
  `[data-tinyfly-embed]` when the script tag has `data-tinyfly-auto`.
- **Size:** about 3 kB gzipped extra (49.6 → 52.7 kB).
- **Build-time tools:** `validateEmbed` and `renderFrame` stay in
  `@algorisys/tinyfly/embed` and the `tinyfly` command.
- **Teaching-only pages:** `tinyfly-embed.iife.js` (~19 kB) is still the smaller choice.
- **Mixing bundles:** loading more than one bundle stays safe; they add to the same
  `tinyfly` global.

## Technical Details

### Test Coverage

- **Unit:** 2,012 tests passing.
- **Browser check:** in Chrome, a page loading only `tinyfly.iife.js` with
  `data-tinyfly-auto` mounted its figure with controls and ran `tinyfly.to()`, with no
  errors.
- **Cross-browser (Chromium, Firefox, WebKit):** the full suite.
