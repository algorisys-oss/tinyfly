# v0.116.0 — Maths animations: linear algebra and calculus

Released: 2026-10-16

A new entry point, `@algorisys/tinyfly/math`, draws maths the way teaching
videos and explorable lessons show it. One figure, written as JSON, plays in a
lesson page, as an explorable the reader drags, and as a 9:16 or 16:9 video.

## Added

- `@algorisys/tinyfly/math`:
  - Figures as JSON: a coordinate plane plus items (grid, axes, vector, basis,
    point, function, parametric, polygon, line, label, equation, tangent,
    riemann, area, taylor).
  - Values: numbers, `[x, y]` vectors and `[a, b, c, d]` matrices, animated by
    ordinary timeline tracks, alongside each item's `draw`, `opacity` and
    (equations) `step`.
  - `mathFigure()` checks a figure up front, with fix-it messages.
- Rendering: one pure layout step (`layoutFigure`) produces shapes, drawn on a
  canvas (`drawDisplayList`) or written as SVG (`displayListToSvg`,
  `mathFigureToSvg`). Every output shows the same picture.
- Built-in TeX subset, no KaTeX:
  - Scripts, fractions, roots, accents, sums and integrals with limits, named
    operators, Greek letters and symbols.
  - Matrices, `\text`, `\color`, `\id` (names a term), and live values
    (`\val{M.det}`).
  - Fixed glyph metrics, so equations lay out the same in browsers, Workers and
    Node.
  - Equation steps whose shared terms glide while the rest fade
    (`morphEquation`).
- Linear algebra:
  - `vec2` and `mat2`, with real eigenpairs.
  - Grids warped by a matrix, î and ĵ, the determinant as an area, and
    eigenlines.
  - Presets: `linearMapFigure`, `determinantFigure`, `eigenFigure`,
    `vectorSumFigure`, `spanFigure`.
- Calculus:
  - Exact symbolic derivatives (`differentiate`, `compileDerivative`) and
    Simpson integration (`integrate`).
  - Tangents and secants, Riemann sums (left, right, midpoint, trapezoid),
    signed areas between curves, and Taylor polynomials whose fractional
    orders grow the next term in.
  - Points riding a curve, hollow points, and derivative plots.
  - Derived numbers for TeX: `ID.slope`, `ID.sum`, `ID.exact`, `ID.value`,
    `ID.degree`.
  - Presets: `tangentFigure`, `secantFigure`, `riemannFigure`, `areaFigure`,
    `taylorFigure`, `limitFigure`.
- A safe expression language for functions: parsed, never `eval`. It has
  implicit multiplication and listed functions including `sigmoid` and `relu`.
- Lessons and embeds:
  - `mathSteps()` writes lesson steps on `lesson()`: `applyMatrix`, `drawOn`,
    `showStep`, `toValue`.
  - `<figure data-tinyfly-math>` embeds (`mountMath`, `mountAllMath`,
    auto-mount) run on the ordinary embed player and controls.
  - `mathExplorable()` gives readers sliders and draggable vectors and matrix
    columns.
  - `mathTarget()` makes a figure a canvas target for videos.
- CDN script `tinyfly-math.iife.js`, about 40 KB gzipped. It works on its own,
  because it carries the embed player and `lesson()`.
- Gallery: Linear Map, Eigenvectors, Equation Steps, Matrix Lesson,
  Derivative, Riemann Sums and Taylor Series.
- Videos: `linear-map-short.mjs`, `riemann-short.mjs`, `eigen-explainer.mjs`
  and `taylor-explainer.mjs`.
- Guide: `docs/math.md`. The capability catalog, the README and the model
  guides cover the new entry point.

## Changed

- `TinyflyPlayer` has a `state` getter: the animated values at the playhead,
  for renderers that draw from values instead of DOM elements.

## Validation

- 76 maths tests:
  - Expression parsing, with a check that expressions cannot read outside
    their scope.
  - Symbolic derivatives checked against finite differences.
  - TeX layout and morphing, figure items and validation, calculus values
    checked against hand calculations.
  - Canvas and SVG determinism, the canvas target, lesson steps, embeds and
    explorables.
- Entry-boundary rules keep the maths core free of DOM and UI code.
- All gallery demos checked at desktop and phone widths; video stills
  reviewed.
