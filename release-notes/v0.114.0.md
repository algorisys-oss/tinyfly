# v0.114.0 — Organic body shapes and measurements

Released: 2026-10-14

Organic characters can be drawn in accurate proportion from size-chart
measurements, and the shape holds at every turn, not only from the front.

## Added

- `body.measurements` on organic characters: tape-measure girths
  `{ height, bust, underbust?, waist, hip }` in any one unit, or a named shape
  from `BODY_SHAPES` (hourglass, pear, rectangle, invertedTriangle, round).
  `bodyShapeProfiles`, `measuredHipWidth` and `resolveMeasurements` are public
  pure functions.
- `body.torsoFront` / `body.torsoBack` side-view depth profiles. Each torso
  section is projected from its width and depth by the turn, so bust, seat and
  belly read correctly in profile and three-quarter views.
- Editor **Body shape** picker for organic figures; saved as JSON body data.

## Changed

- Measured hips set the hip-joint spacing and thigh width; explicit `torso`,
  `torsoFront`, `torsoBack` and `hipWidth` still win. Clothing follows the
  shaped torso contour.
- `softCartoonCharacter('youngWoman')` gains a stylised side profile; passing
  new measurements replaces a preset's torso.
- Unmeasured organic bodies are unchanged: depth defaults to `torso × depth`.

## Validation

- All 3,841 tests across 240 files pass, including new profile, unit,
  validation, projection-symmetry, leg-spacing, preset and editor picker tests.
- Contact sheets of all five shapes, bare and dressed, at five turns visually
  reviewed.
