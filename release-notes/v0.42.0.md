# v0.42.0

**Release Date:** 2026-07-22

**Phase C begins** — polygon & star shapes.

## Highlights

- **⬡ Polygon and ★ Star** in the Elements panel — one click to add.
- **Parametric.** Select a shape and edit **Sides** (polygon) / **Points** (star)
  and the star's **Inner %** in Properties. The geometry regenerates live.
- **Resizable.** Drag the box handles and the shape rescales to fill the new
  size — sides and points stay crisp at any scale.
- **Just a path.** Under the hood each shape is a closed `PathElement` with a
  generated `d`, so it renders, animates, and exports everywhere with no special
  cases (DOM / Canvas / SVG / raster export / embeds).

## How it works

`src/editor/utils/poly-star.ts` is a pure, unit-tested geometry helper
(`polygonVertices`, `starVertices`, `verticesToPath`, `polyStarPath`). A shape is
a path with an extra `shape: { kind, points, innerRatio }` spec; the scene store
regenerates the path `d` from that spec whenever the sides/points change
(`updateShape`) or the box is resized (`updateElement`). In the editor a
parametric shape shows the box + resize handles instead of per-vertex control
points, so it scales as a unit.
