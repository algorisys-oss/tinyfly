# v0.66.1

**Release Date:** 2026-09-14

Typing in the studio's Property panel works again.

## Fixed

### Text fields lost focus after every character ([#1](https://github.com/algorisys-oss/tinyfly/issues/1))

- **Symptom:** typing into a text element's **Content** field stopped after one
  character; you had to click back into the field for every keystroke. The hex
  colour, font family, media URL and SVG path fields had the same problem.
- **Cause:** each edit replaces the element object in the scene store, and the
  panel's type-specific section was rebuilt whenever that object changed, which
  destroyed the focused input. Auto-save ran at the same moment but was not the cause.
- **Fix:** the section is rebuilt only when a different element (or type) is
  selected, and its fields read a live view of the selected element, so they
  update in place.

## Technical Details

| File | Description |

| `src/editor/components/property-panel.tsx` | Keyed type-specific section, live element view |
