# v0.104.0

**Release Date:** 2026-10-12

Colour anime characters with expressive eyes, from children to older adults,
using Tinyfly's existing poses, expressions and turnarounds.

## Added

- **Anime cast**: `ANIME_CAST` provides eight editable presets: `animeBoy`,
  `animeGirl`, `animeYoungMan`, `animeYoungWoman`, `animeMan`, `animeWoman`,
  `animeOlderMan` and `animeOlderWoman`. They also appear in `CHARACTER_CAST`
  and work with `castMember`.
- **Anime faces**: `face.style: 'anime'` draws almond eyes with coloured irises,
  pupils, highlights and optional lashes. `iris`, `lashes` and `ageLines`
  customise the face. Existing blink, gaze, brow and mouth fields animate it.
- **Editor controls**: the Character element offers face style, iris colour,
  eyelashes and age creases. Both Character and 3D Scene cast pickers include
  the new presets; appearance settings round-trip through scene JSON.
- **Colour Anime Cast example**: eight characters, selectable expressions,
  blinking, full turnarounds and face close-ups, with a standalone page export.
- Public `FaceOptions`, `PupilCircle` and `AnimeCastName` types, and face style
  discovery in the character capability catalog.

## Validation

- Pixel tests cover iris visibility, profile/back views, blink and lid closure,
  expressions, gaze, lashes, age creases and all eight presets through turns.
- Existing simple faces retain their pixels. Cast presets survive JSON
  round-trips and editor switching clears anime-specific options.
- The gallery and exported standalone page animate in Chromium; expressions
  and turnaround controls update the drawing without browser errors.

## Upgrade Notes

- Existing faces stay simple unless `face.style: 'anime'` is selected.
- Presets are stylised starting points. Hair, clothing, build and face details
  remain editable; the names do not restrict appearance or supported motion.
- Nested option overrides replace their corresponding preset object, as with
  existing `castMember` calls. Spread the preset's face to retain its fields.
