# v0.59.0

**Release Date:** 2026-09-14

Refreshing any page now works on Hostinger and other common hosts, the editor
moves to `/studio`, and the course gains its Foundations module.

## Fixed

### "Page not found" when refreshing

Addresses such as `/studio`, `/learn/…`, `/examples/<id>` and `/docs/…` exist only
inside the app. Opening one directly or refreshing it asked the server for a file
that doesn't exist. The build now carries the fallback for each kind of host:

| Host | File in the build |
|---|---|
| Apache, LiteSpeed (Hostinger, most shared hosting) | `.htaccess` |
| Netlify, Cloudflare Pages | `_redirects` |
| Vercel | `vercel.json` (repository root) |
| GitHub Pages and similar | `404.html`, a copy of the app |

The `.htaccess` was tested under Apache:

- `/`, `/studio`, deep `/learn` links, `/examples/<id>`, `/docs` and `/docs/<page>`
  all open;
- the `docs/*.md` and `llms.txt` files are served as text;
- hashed assets are cached long-term.

`DirectorySlash Off` stops `/docs` (also a folder of markdown) from redirecting to
`/docs/`.

## Changed

### The editor is at `/studio`

The site is tinyfly.app, so `/app` read oddly. The editor now lives at `/studio`.
`/app` redirects there and keeps `?example=`, so links from v0.56–v0.58 still work.

## Added

### Learn: Foundations, animation as data

A new first module for `/learn`, with 3 lessons and 8 steps:

- **Keyframes:** a timeline is JSON, times are milliseconds, more keyframes.
- **Tracks and values:** one track per property, colours.
- **Easing and loops:** easing on the arriving keyframe, a cubic-bezier, `loop` and
  `alternate`.

Learners edit a timeline definition and call `play(animation)`. The runner plays
definitions on `data-tinyfly` elements with the same scrubbing, replay and checks
as `live` code.

  redirect and all 18 course steps.
