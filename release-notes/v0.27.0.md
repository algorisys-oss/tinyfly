# v0.27.0

**Release Date:** 2026-07-22

**Symbol swap** — animate *which* symbol an instance shows over time. The lip-sync
primitive, no bones required.

## Highlights

- **Swap sets + `swapIndex`.** A symbol instance can hold an ordered **swap set**
  of symbols. Animate a `swapIndex` track and the instance shows
  `set[floor(swapIndex)]` at each moment — swapping mouth shapes for lip-sync, or
  any "which drawing shows now" effect.
- **Property-panel editor.** Select a symbol instance → **Symbol Swap** section:
  add symbols from the Library, reorder with ↑/↓, and **+ Add swap track** to drop
  a `swapIndex` track that steps through the set across the timeline. Then time
  the swaps by editing its keyframes in the Dope Sheet or Curves.
- **Step behaviour for free.** Flooring a plain numeric `swapIndex` track gives
  the hold/step behaviour swapping needs — no new engine concept.

## How it works

The instance gains an optional `swapSet: string[]`. In the DOM preview the shown
symbol is a reactive function of the animated `swapIndex` at the playhead
(`shownSymbolId(inst, index)`), so it changes live as you play or scrub. The
engine is untouched — `swapIndex` is an ordinary numeric track the DOM adapter
ignores for styling.

## Added

- `swapSet` on `SymbolInstanceElement`; `shownSymbolId()` helper (tested).
- Reactive swap rendering in the DOM preview.
- **Symbol Swap** editor in the Property Panel (build/reorder the set, add a swap
  track). `PropertyPanel` now receives the project store.
