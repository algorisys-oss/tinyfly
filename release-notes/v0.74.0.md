# v0.74.0

**Release Date:** 2026-09-27

Facial expressions for the stick figure. Eyes that widen, close and look around,
eyebrows that lift and slant, and a mouth that grins, wails or gasps. Like the joints,
every feature is a number, so faces blend and animate on the timeline.

```js
import { withExpression, poseTracks, POSES } from '@algorisys/tinyfly/characters'

drawStickFigure(ctx, withExpression(POSES.wave, 'wink'))

poseTracks('hero', [
  { time: 0, pose: 'rest', expression: 'happy' },
  { time: 800, expression: 'surprised' },               // only the face changes
  { time: 1600, pose: 'shrug', expression: 'confused' },
])
```

## Added

- **Face fields** on every pose: `leftEye` / `rightEye` (0 shut, 1 normal, up to 1.6
  wide, where the whites show), `leftBrow` / `rightBrow` (-1 lowered to 1 raised),
  `browTilt` (-1 angry to 1 worried), `lookX` / `lookY` (gaze), `mouthWidth`. `blink`
  still closes the eyes on top.
- **Mouth shapes:** closed, it curves with `smile`. Open, it is a grin (smile > 0.3),
  a wail (smile < -0.3) or an O. Shut eyes arch upward on a smiling face (a laugh).
- **`EXPRESSIONS`:** 18 ready-made faces: neutral, happy, joyful, sad, crying, surprised,
  shocked, angry, furious, worried, scared, confused, skeptical, thinking, sleepy,
  disgusted, smug, wink. Each sets every face field, so any two blend.
- **`withExpression(pose, face)`** puts a face on any pose; **`poseTracks`** keys take an
  `expression`, alone or with a `pose`.
- **Gallery:** the Stick Figure card has an expression picker and a close-up of the face.

## Changed

- The built-in poses `wave`, `cheer`, `shrug`, `think`, `sad` and `surprised` now carry
  matching expressions.
- Figures now have eyebrows. A figure drawn with default settings looks slightly
  different from v0.73.0.

## Upgrade Notes

- **No breaking changes** to the API. `StickPose` has new fields; code that builds
  poses with `pose({...})` or spreads `REST_POSE` gets their defaults. A hand-written
  object literal typed as `StickPose` needs the new fields (spread `REST_POSE` first).
