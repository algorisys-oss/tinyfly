# v0.45.4

**Release Date:** 2026-07-22

Documentation refresh — the web help now covers every feature.

## Highlights

The in-app **Docs** (`/docs`) and the README are brought fully up to date with the
recent releases, so a beginner can discover and follow every feature:

- **Getting Started** — a new “Going further” section pointing at shapes/drawing,
  shape morph, camera, precision tools, onion skinning, and export.
- **Editor Guide** — new/updated coverage of:
  - ✒️ **Pen tool** (draw, Alt-cusp, adjust anchors/handles, snapping, finish/undo)
  - ⬡ **Polygon** / ★ **Star** parametric shapes
  - 🌀 **Shape Morph** authoring
  - ▦ **Grid**, 🧲 **Snapping**, 📏 **Rulers & guides**
  - 🧅 **Onion skinning**
  - **Camera** — inspector, on-stage ✋ Pan, and the timeline lane
  - **Export formats** — GIF, WebP, MP4, and the new **Sprite** sheet
- **API Reference** — `morphPath` / `isPathData` and the path-morph interpolator
  routing; the sprite-sheet layout helpers (`spriteSheetLayout`, `frameCell`,
  `spriteFrameTimes`, `spriteSheetMeta`).
- **README** — feature list updated with camera authoring, shapes, pen tool, shape
  morph, grid/snapping/guides, onion skinning, and sprite-sheet export.

## Also in this release — scene-bar UX fix

The default (single-scene) tab looked cluttered — a tiny empty thumbnail box next
to the name and a dashed “crop-mark” add button. Now:

- Tab **thumbnails only show when there's more than one scene** (a lone scene
  reads cleaner as a plain named tab).
- The scene tab and **+** add button share a clean, defined chip style instead of
  the dashed placeholder look.
