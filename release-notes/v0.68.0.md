# v0.68.0

**Release Date:** 2026-09-15

The course's open items are done: three new steps, warnings shown in lessons,
and ways to take your work out of the course. Fixing the warnings turned up an
engine bug: `live` never passed on warnings at all.

## Added

### Three new course steps (9 modules, 28 lessons, 67 steps)

- **Capstone → Hero → A glow that follows the pointer:** a plain object aimed with
  `quickTo`, drawn on the ticker, taken off it by `onLeave` and put back by `onEnterBack`.
- **Capstone → Details → A magnetic button:** `quickTo` springs measured from
  `offsetLeft` / `offsetTop` (which ignore the pull's own transform), home on `pointerleave`.
  The "open the whole page" pointer moved here, since this is now the last step.
- **Scroll → Smooth scrolling:** `live.smoothScroll({ scroller, smooth, effects })` with
  `data-speed` and `data-lag` layers.

### Warnings in lessons

- A selector that matches nothing, `drawSVG` on something that isn't a shape, a `spring` on a
  colour, or a value that snaps because it has no start now appear under the code in plain
  language: what went wrong in the step's terms, and what to change.

### Copy as page / Open in editor

- The last step of every module offers **Copy as page**: the step's markup and your code as a
  standalone HTML file, with `live`, `play` and `root` defined as in the course.
- For lessons that play JSON (Foundations), **Open in editor** creates a new studio project
  with a box for each target and the tracks as you wrote them.

### The course in `llms-full.txt`

- After the docs: every module, lesson and step with its link, explanation and solution.

### `new Stage({ onWarning })`

- A stage can take `onWarning`, and every `live` tween and timeline on it reports there.
  A timeline's own `onWarning` still takes precedence.

## Fixed

- **`live` dropped every warning.** Tweens and timelines made through `live` were never
  given an `onWarning`, so their warnings went nowhere. `Stage` now supplies one.
- **A spring on a colour eased without saying so.** It still eases, and now warns.
- **Keyboard users were trapped in the course's code box**, because Tab inserts spaces.
  Now **Esc then Tab** moves on, a line under the box explains this, and the code, preview,
  checks and warnings are labelled for screen readers.
- **The package facts given to AI tools (`llms.txt`) were out of date.** They said tinyfly
  wasn't on npm and used the old `tinyfly/…` entry points. They now name
  `@algorisys/tinyfly` and every entry point, including `teach`, `embed`, the framework
  wrappers and the CLI.

### Test Coverage

- **Course gate:** a new check that no step's solution raises a warning, alongside "solution
  passes" and "starter fails", for all 67 steps.
- **Unit:** stage warnings (4), `learnerWarning` (6), `lessonSample` (3), course in
  `llms-full.txt` (1), and a compiled Copy as page for every step.
- The new steps, the warnings, Open in editor and Esc then Tab were also checked by hand in
  Chromium.

## Upgrade Notes

- **No breaking changes.** `StageOptions.onWarning` is optional. If you already pass
  `onWarning` to a timeline, you may now also see warnings for a spring on a non-number.
