# v0.56.0

**Release Date:** 2026-09-13

A landing page at tinyfly.app built with tinyfly, the editor moved to `/app`, and
the tools that keep award-style pages working through resizes, breakpoints,
reduced motion and route changes. tinyfly is now MIT licensed, and WebKit joins
the cross-browser checks.

## Added

### Landing page at `/`, editor at `/app`

The site root introduces tinyfly using tinyfly:

- a masked split-text headline;
- a fireflies canvas drawn on the ticker, drifting toward the pointer;
- a live playground: edit `live` code and see both the animation and the JSON it
  compiles to;
- a pinned feature story;
- a gallery strip that leans with scroll speed, count-up numbers, and springy
  closing type with a magnetic button.

All of it runs under `live.matchMedia`, with a real reduced-motion mode.

- **Returning users** see **Continue where you left off**.
- **Lighter front page:** the editor, Examples, Showcase and Docs are loaded
  only when visited. The landing page's first script is 49 KB gzipped, and it
  loads no editor or exporter code.
- **Splash:** the splash only shows when opening `/app` directly.
- **Old links:** `/?example=` links still reach the editor.

### Brand mark

A fly icon and an animated BETA badge are shared by every header:

- **Icon:** its wings flutter now and then, and while hovered.
- **Badge:** a sweeping shine and a soft glow.
- **Reduced motion:** all of it stays still.

The fly is also the favicon.

### Values that survive a resize

- **Function values:** `x: (index, target) => …` is called per target.
- **`tl.invalidate()`:** rebuilds a live timeline from the same calls. It
  rewinds, re-runs function values and start values, and returns to the same
  progress.
- **`scrollTrigger` start/end functions and `invalidateOnRefresh: true`:** a
  pinned horizontal section re-measures its travel on resize or rotation.
- **`splitText({ autoSplit, onSplit })`:** re-splits when the width changes or
  fonts load, killing the animation built on the old pieces.
- **Phone address bar:** its height-only resizes no longer refresh scroll
  triggers, so pins stop jumping mid-scroll.

### `live.context()` and `live.matchMedia()`

- **`live.context(fn, scope)`:** collects everything the live API creates, and
  `ctx.revert()` undoes it. That includes:
  - timelines, with their scroll triggers and pins;
  - split text and draggables;
  - ticker callbacks and returned cleanups.

  Elements get their original inline styles back. `ctx.add()` covers work
  created later, for example in event handlers.
- **`live.matchMedia()`:** runs setups while media queries match, reverts them
  when the queries stop matching, and re-runs them when the conditions change.
  `ctx.conditions` says which queries match. The Agency Landing Page uses it for
  a real reduced-motion mode.

### `live.quickTo`

`live.quickTo(target, property, { duration, ease, spring })` returns a setter that
re-targets one reused tween from the value on screen:

- **Fewer writes:** many calls in a frame cost one write.
- **Springs:** they keep their momentum.

The pointer and scroll-velocity demos and both full pages now use it.

### Release script

`npm run release:oss` and `npm run release:oss:dry-run` wrap the OSS publish and
CDN tagging.

## Changed

- **License: MIT** (was AGPL-3.0 with a commercial option). `LICENSE`, the
  README, `package.json` and `llms.txt` now agree.
- **The editor's address is `/app`.** Links, docs and checks are updated.

## Fixed

- **WebKit e2e:** the run now works from a VS Code snap terminal. The runner
  removes the snap's GTK/GIO variables, which made WebKit's network process fail
  every page load.
- **MP4 check isolation:** the MP4 check runs in its own page, so Linux WebKit's
  GStreamer crash (inside WebKit) no longer hides the other export results.

### Test Coverage

- **Unit:** 1,735 tests passing. New ones cover function values and `invalidate`,
  resize refresh, `autoSplit`, contexts and matchMedia, `quickTo`, the landing
  playground and motion, and the showcase's reduced-motion mode.
- **Cross-browser:** Chromium 150, Firefox 153 and WebKit 26.5 pass every check.
  MP4 export in Linux WebKit is reported as a note. New checks:
  - the landing page;
  - the showcase's pin distance after a resize, which ends flush at 0.0px;
  - toggling reduced motion, which removes and restores the pin.
