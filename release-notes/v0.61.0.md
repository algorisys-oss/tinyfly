# v0.61.0

**Release Date:** 2026-09-14

Smooth scrolling with parallax layers, like GSAP's ScrollSmoother, that keeps
scroll triggers and pins working unchanged.

## Added

### `live.smoothScroll()`

```js
const smoother = live.smoothScroll({ smooth: 0.9, effects: true })

// <h2 data-speed="0.8">   scrolls at 80% of the page's speed
// <img data-lag="0.3">    catches up 0.3s after the page moves

smoother.scrollTo('#contact', { offset: -80 })
```

- **The real scroll position moves.** Wheel input is eased, but the page is not moved
  inside a transformed wrapper. Scroll triggers, sticky pins, `position: fixed`,
  anchor links, find-in-page and scroll restoration all work unchanged.
- **Native where it should be.** Touch, keyboard and scrollbar scrolling stay native
  and smoothing follows them. Pinch-zoom, sideways wheels and scrollable areas inside
  the page (or anything marked `data-smooth-ignore`) are left alone.
- **Parallax layers.** `data-speed` and `data-lag` are written to CSS `translate`, so
  they combine with tweens on `transform`.
- **Measured with the layout.** Layers rest while scroll triggers measure, and are
  measured again after pins change the layout, on resize and `live.refreshScroll()`.
- **Controls.** `scrollTo(offset | element | selector, { offset, duration })`,
  `paused()`, `state`, `refresh()`, `kill()`. Contexts and `matchMedia` kill it on
  revert.
- **Reduced motion.** No smoothing and no effects.

`SmoothScroll` is also exported from `tinyfly/drivers`, and
`ScrollDriver.onRefresh()` lets anything that moves elements by scroll take part in
measuring.

The Agency Landing Page showcase turns it on outside reduced motion.

## Technical Details

| File | Description |
|------|-------------|
| `src/drivers/smooth-scroll.ts` | `SmoothScroll` |
| `src/drivers/scroll-driver.ts` | `ScrollDriver.onRefresh` before/after measuring |
| `src/compat/gsap/live.ts` | `live.smoothScroll`, `refreshScroll` covers smoothers |
| `src/examples/showcases/agency-landing.js` | Smooth scrolling and parallax headings and tiles |

### Test Coverage

- **Unit:** 1,919 tests passing (9 new: easing, wheel units, ends, native scrolls,
  reduced motion and pause, `scrollTo`, `data-speed`, `data-lag`, refresh order).
- **Cross-browser (Chromium, Firefox, WebKit):** a real wheel eases the window's
  scroll position through the frames in between, and a `data-speed` layer lands within
  1.5px of its expected offset, with pins, resize and reduced-motion checks still
  passing on the same page.
