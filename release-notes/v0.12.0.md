# v0.12.0

**Release Date:** 2026-07-11

Minor release that adds **video export**, a **stroke write-on** effect on the DOM
renderer, and a **resizable preview/timeline split** — moving tinyfly closer to a
one-stop tool for producing a finished promo clip.

## Highlights

- **MP4 / WebM export** - Export As → **Video** records the animation to a video
  file via the browser's MediaRecorder, with a size (defaults to the canvas),
  FPS, and codec picker (MP4 where the browser supports it, otherwise WebM), plus
  a progress bar.
- **Stroke write-on** - A path's stroke can now "draw itself on" on the **DOM**
  renderer (previously SVG-only), via animated `stroke-dasharray` /
  `stroke-dashoffset`. A one-click **Write On** preset builds it from the path's
  measured length.
- **Resizable preview** - Drag the splitter between the preview and the timeline
  to resize them; double-click the splitter to reset.

## Added

- **`exportToVideo` / `getSupportedVideoCodecs` / `isVideoExportSupported` /
  `downloadVideo`** in `tinyfly/export` - Frame-paced MediaRecorder capture of a
  canvas stream, with a `renderFrame(ctx, timeMs)` callback (mirrors the GIF
  exporter). Feature-detects MP4/WebM codecs.
- **Video tab in the Export dialog** - Size / FPS / format controls and an
  **Export Video** button with live progress. Renders the scene through the
  Canvas renderer (shapes, text, lines, paths); video/image layers are DOM-only
  and are not captured.
- **"Write On" preset** in the preset panel (shown when a single path is
  selected), with a duration control.

## Changed

- The DOM renderer binds animated `strokeDasharray`/`strokeDashoffset` directly
  on the `<path>` element (the adapter styles the wrapping div), so write-on
  works on the default renderer.
- The scene→Canvas target mapping was extracted to `utils/scene-to-canvas.ts` and
  is shared by the live preview and the video exporter.
- The editor's preview and timeline are now separated by a draggable splitter;
  the timeline height is user-controlled (120–560px).

## Technical Details

### Changed Files

| File | Description |
|------|-------------|
| `src/engine/export/video.ts` | MediaRecorder-based `exportToVideo` + codec detection + download |
| `src/editor/components/export-dialog.tsx` / `.css` | Video export tab, options, progress |
| `src/editor/utils/scene-to-canvas.ts` | Extracted scene→Canvas target mapping (shared) |
| `src/editor/components/preview-panel.tsx` | Uses shared mapping; binds animated stroke-dash on `<path>` |
| `src/editor/components/preset-panel.tsx` | "Write On" preset for path elements |
| `src/editor/editor.tsx` / `editor.css` | Draggable preview/timeline splitter |

### Test Coverage

- 525 tests passing (+3 for video codec detection). Verified live in Chrome: a
  360×640 promo exported to a valid H.264 MP4 (181 frames, 6.1s), a path stroke
  wrote on from hidden to full on the DOM renderer, and dragging the splitter
  resized the preview.
