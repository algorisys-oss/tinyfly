# v0.129.0 — Presentations: a talk from a tinyfly page

Released: 2026-11-19

A new entry, `@algorisys/tinyfly/present`, makes a page a slide deck: the
presenter steps through with a clicker, and on each click a scene plays to
its next beat while the slide's text appears. One command builds the deck
into a single HTML file that opens offline.

## Added

- **`createDeck(root, options)`**: `[data-slide]` sections become slides on
  a fixed stage (1920 × 1080 by default) scaled to the window.
  `[data-step="k"]` fragments appear on click `k` (`data-reveal`: `pop`,
  `fade`, `none`), `[data-notes]` holds speaker notes. Keys and clicker
  buttons step forward and back, typed digits and Enter jump to a slide,
  `B` / `W` blank the screen, `F` is full screen, `R` replays a step, and the
  place is kept in the URL hash. A second press while a step is playing
  shows its end and never skips a step.
- **A scene per slide**: `scenes: { id: () => ({ marks, draw(ctx, frame), update(frame) }) }`.
  `marks[0]` ends the entrance and `marks[k]` ends click `k`; the deck plays
  `frame.time` from mark to mark. `frame.clock` never stops, for motion that
  loops while the scene waits. Scenes are built when first needed, and one
  that throws is stopped without stopping the deck.
- **Countdowns**: `<button data-timer="30">` on a step. Next starts it,
  Next again ends it early, and scenes get `frame.timer`
  (`state`, `elapsed`, `seconds`, `sinceEnd`) so a figure can act while it runs.
- **Presenter window** (`P`): notes, elapsed time, time left of
  `slotMinutes`, the slide's clicks, and what the next press will do. It is
  written into a blank window, so it works from `file://`.
- **`DeckState`**: the deck with no page. Slides, steps, scene clocks and
  countdowns as plain state; every time-dependent call takes `now`.
- **`tinyfly present <deck.html> [-o out.html] [--allow-remote]`** and
  `inlineDeck()`: scripts and stylesheets inlined, images, fonts and media
  as data URIs. Exit 1, nothing written, when a local file is missing, when
  something cannot be inlined (`srcset`, `@import`, a module that imports
  other files), or when the page still loads from the network.
- **In the browser bundle**: `tinyfly.createDeck`, so a deck needs one
  vendored script. Rehearse with `deck.seek(slide, step, ms)`.
- All visible text comes from `labels` (`DEFAULT_DECK_LABELS`).

## Docs

- New guide: [Presentations](../docs/presenting.md). README, capabilities

  countdown).

## Validation

- Unit tests for `DeckState` (steps, snap, countdowns, back, jumps, late
  marks), `createDeck` in happy-dom (markup, keys, clicks, hash, labels,
  failing scenes, destroy) and `inlineDeck` (inlining, script escaping,
  what it reports).
- Entry-boundary test: `present` reaches no other part of tinyfly.
- The built example walked in headless Chromium from `file://`: every step,
  back, a typed slide number, the countdown to its end and ended early, the
  presenter window; no console errors and no network requests.
