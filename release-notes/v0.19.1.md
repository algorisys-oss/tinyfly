# v0.19.1

**Release Date:** 2026-07-22

A follow-up to the My Animations gallery: thumbnails now stay **current while you
edit**, and there's a complete **file-format reference** for integrations.

## Highlights

- **Live gallery thumbnails.** Thumbnails re-render on a debounced timer as you
  work, and a project's thumbnail is captured when you switch away from it — so a
  brand-new animation shows a real preview in the gallery without you having to
  open the gallery first. (Previously a thumbnail was only captured when the
  gallery opened.)
- **File-format documentation.** A new [File Format](../docs/file-format.md) doc
  (also in the in-app docs viewer at `/docs`) documents the complete tinyfly JSON
  format so others can generate, consume, and integrate animations: the
  high-level **Animation Document** (`elements` + `tracks` + `duration`), the
  engine **Timeline Definition**, and the **Project** and **Sequence** shapes —
  with element/track/keyframe references, the animatable-property and easing
  lists, gradients, motion paths, and determinism notes.

## Added

- **File-format reference** (`docs/file-format.md`) wired into the docs viewer
  (`src/docs/docs-viewer.tsx`) as a "File Format" page.
- Debounced live thumbnail capture in the editor, plus an outgoing-project
  capture on gallery open/new/switch (`captureThumbnailFor` / `captureOutgoingThumbnail`).

## Changed

- Thumbnail rendering is now parameterized by `(id, elements, canvas)` so a
  project's preview can be snapshotted from state captured *before* the scene
  store reloads — no races when switching projects.
