# v0.55.0

**Release Date:** 2026-09-13

Award-site motion on the GSAP-style API, a full-page showcase built with it,
docs made complete and readable by language models, and a core half the size.

## Added

### Scroll triggers, with pinning

`scrollTrigger` on `live.timeline()` or any `live` tween, with GSAP's option names:

```js
live.timeline({ scrollTrigger: { trigger: '.work', start: 'top top', end: '+=2000', scrub: 0.5, pin: true } })
  .to('.track', { x: -1600, ease: 'none' })

live.from('.card', { y: 60, opacity: 0, scrollTrigger: { start: 'top 80%', toggleActions: 'play none none reverse' } })
```

- `scrub` (exact or smoothed), `pin`, `toggleActions`, `once`, `end: '+=600'` / `'+=150%'`,
  and `onUpdate({ progress, velocity, direction })`. `live.scrollTrigger(vars)`
  gives callbacks with no animation; `live.refreshScroll()` re-measures.
- **Pinning automates the sticky recipe:** a spacer as tall as the element plus
  the pinned distance, and `position: sticky`. The browser does the holding, so
  nothing is written while scrolling. `kill()` and `stage.destroy()` remove it.
- **Scrolling does no layout reads.** `ScrollDriver` now measures on start and
  resize only; a scroll event reads the scroll offset alone, and the smoothing
  loop stops once it catches up. `driver.update(scrollTop)` accepts positions
  from virtual scrollers; Lenis-style scrollers work unchanged.

### `live.splitText`

Characters (grapheme clusters), words and rendered lines, with `mask` wrappers for
reveals from behind an edge. Inline markup such as `<em>` and `<a>` is cloned
into each line it spans, spaces stay real text, and the element gets an
`aria-label`. `revert()` restores it.

### `drawSVG`

`live.from('.line', { drawSVG: 0 })`, `drawSVG: '20% 80%'`, `'10 50%'`, `true`.
Each element's stroke length is measured once, and the draw compiles to
`strokeDasharray` / `strokeDashoffset` tracks.

### Springs from `live`

`spring: true | 'bouncy' | { preset, stiffness, damping, mass, velocity }` turns a
tween's numeric properties into spring tracks, which stay deterministic and
serializable. **Interrupting a motion keeps its momentum:** without a `velocity`,
the spring starts at the speed the property already had. A drag's `onRelease`
velocity can be passed per property. `SPRING_PRESETS` now lives in the engine,
and the editor's spring inspector uses it.

### Flip shared elements

Elements with the same `data-flip-id` are one thing. A thumbnail grows into a
separate hero element and back, and `fade: true` cross-fades them.

### Plain-object targets and a ticker

`live.to(mesh.position, { x: 2 })` tweens any object, starting from its own
values. `live.ticker.add((time, deltaTime, frame) => …)` runs after each frame's
values are applied: the place to render a canvas or a WebGL scene.

### Agency Landing Page showcase

A full scrolling page at `/showcase/agency-landing`, and a band on the Examples
page with **Open the page** and **Copy code**. It uses all of the above together:

- a masked headline reveal
- a pointer-lit canvas that pauses off-screen
- a hide-on-scroll nav and a velocity marquee
- scroll-lit copy
- a pinned horizontal work section
- object count-ups
- drawn icons with spring hovers
- a shared-element lightbox
- spring type and a magnetic button

It is responsive down to phone widths.

### New GSAP-style demos

Canvas from Object Tweens, Line Mask Reveal, Pinned Horizontal Scroll, Spring
Release, Shared Element Gallery (38 in total). The SVG Line Draw, Draw & Follow
and Split Text Reveal demos now use `drawSVG` and `splitText`.

### Docs for language models, and a complete pass over the docs

- `llms.txt` is at the repo root. A test keeps it in step with the docs.
- The built editor serves `/llms.txt`, `/llms-full.txt` and every doc as raw
  markdown at `/docs/<page>.md`.
- One doc manifest feeds these files and the in-app viewer.
- **In-app viewer:** all 14 guides, grouped, with a URL per page, working links
  between docs, and section-level search.
- **Audit fixes:**
  - the file format now covers every track kind;
  - the API reference covers timeline queries, type guards, Stage, drivers,
    media sync and video export;
  - the editor guide matches the current toolbar and track form;
  - stale CDN versions and player paths are corrected.

### `tinyfly/adapters`

The DOM, Canvas, SVG and WebGL adapters get a package entry, so the documented
imports resolve.

## Changed

### Exporters moved to `tinyfly/export`

The GIF, WebP, MP4, video, sprite-sheet, CSS and Lottie exporters were half the
engine entry. Pages that only play animations no longer pay for them:

| Bundle (gzip) | v0.54.1 | v0.55.0 |
|---|---|---|
| `tinyfly` engine entry | 26.8 KB | 15.8 KB |
| `tinyfly.iife.js` script tag | 37.3 KB | 32.1 KB, including every feature above |

## Fixed

- **GSAP ease names:** `power2` compiled to a quadratic curve, but in GSAP it is
  cubic. `power1` is now quad and `power2` cubic, as in GSAP. Animations using
  `power1` or `power2` change slightly.
- **Fast scrolls across a short range:** a scroll that jumped across it, or a page
  loaded already past it, fired no `onEnter` / `onLeave`. Both now fire, in order.
- **Motion-path tracks ignored `endDelay`.**

## Upgrade Notes

- Import exporters from `tinyfly/export`:
  `import { exportToCSS, exportToGIF } from 'tinyfly/export'`. The script-tag
  global no longer has them.
- `power1.*` and `power2.*` eases now match GSAP (quad and cubic). To keep the old
  look of `power2`, use `power1`.
- `ScrollDriver` measures on start and resize, not on every scroll. After a
  layout change a resize would not catch, such as images loading, call
  `driver.refresh()` or `ScrollDriver.refreshAll()`. `onUpdate` now also receives
  `velocity`.
