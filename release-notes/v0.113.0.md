# v0.113.0 — Decision-focused cricket cameras

Released: 2026-10-13

Fixed review cameras frame the relevant foot, crease and wicket arrival, with
configurable public framing and optional reference overlays.

## Added

- Front-foot review and striker/bowler crease presets. Front-foot framing uses
  the native ankle at release; run-out framing includes the approaching batter.
- Owned cricketCameraFraming defaults, physical cricketCameraReview events and
  optional cricketDecisionOverlay crease references. No automatic decisions or
  playback changes are introduced.
- Camera pitch/distance/fov and fixed-view target options; collapsed example
  framing controls, explicit Inspect moment and JSON export of selected options,
  camera tracks and overlays. Camera names now use a full-width selector.

## Fixed

- Striker-crease inspection selects the keeper’s receipt event for field-and-throw
  plays. Wide framing includes the sideways-moving keeper and batter at collection.
- Ball-follow yaw rotates the original offset, with elevation/distance overrides.
  Original eight view defaults retain their geometry.
- Explicit distant/custom framing writes a conservative far-plane track; 3D
  scene projection and clipping now honor animated camera far.

## Validation

- Release gate passed with no remaining findings; all 3,827 tests across 239
  files, TypeScript, app/public builds and generated docs passed.
- 273 Chromium/Firefox/WebKit checks validated, including a focused rerun of
  12 closed-disclosure visibility checks; six expanded-panel keyboard checks
  and current Wide/throw review checks passed across all three browsers.
- 21 native camera regressions and 32 exact comparisons with published v0.112.0
  default camera tracks passed; desktop/phone decision views visually checked.
- Publication and published consumer verification in progress.
