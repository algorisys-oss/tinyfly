# v0.62.0

**Release Date:** 2026-09-14

Timeline callbacks and control on `live`, as in GSAP. `onUpdate` now sees the frame
it runs for, and a second, poster-style Ganesh Chaturthi showcase is added.

## Added

### Callbacks and control

```js
const tl = live.timeline({ onRepeat: () => …, onReverseComplete: () => … })
  .to('.intro', { opacity: 1, onStart: () => …, onComplete: () => … })
  .call(showMenu, [menu])
  .addPause('+=0.5', () => waitForClick())
  .addLabel('details')
  .to('.details', { y: 0 })

tl.tweenTo('details', { duration: 0.8, ease: 'power2.inOut' })
live.delayedCall(2, hideToast)
live.killTweensOf('.card', 'x,y')
```

**Timelines**

- `tl.call(fn, params, position)` runs a callback when the playhead crosses it, in
  either direction. One placed after the last tween extends the timeline to reach it.
- `tl.addPause(position, callback)` stops exactly there; `tl.play()` continues.
- `tl.tweenTo(position)` / `tl.tweenFromTo(from, to)` pause the timeline and animate its
  playhead to a time or label, firing callbacks on the way.

**Callbacks**

- `onRepeat` and `onReverseComplete` work on timelines and single tweens.
- Tween `onStart`, `onUpdate` and `onComplete` inside a timeline now run at that tween's
  own times. They were ignored before.

**On `live`**

- `live.delayedCall(delay, fn, params)` runs a call on the stage's clock; `kill()`
  cancels it.
- `live.killTweensOf(target, properties?)` stops what moves those targets in every live
  timeline.

**When callbacks fire**

- They fire when the playhead crosses their time: playing, looping, yoyoing, waiting out
  `repeatDelay`, or scrubbed with `progress()`, so scroll scrubs run them. `seek()` jumps
  without firing, as in GSAP.
- A pure `playheadCrossings()` works out what each frame passed.

### Ganesh Chaturthi Poster showcase

`/showcase/ganesh-chaturthi-poster` is a greeting-card poster drawn as SVG.

- **Artwork:**
  - A cream background with marigold garlands.
  - "Ganesh Chaturthi" in a serif, over a rising growth arrow.
  - A four-armed Ganesh ji with axe, conch, blessing hand and modaks, flowing red drapes
    and a seated dhoti, on a teal throne over a rangoli.
- **Animation:**
  - Springy title letters and garlands that swing in.
  - An arrow that draws in, falling petals, and a petal burst when tapped.
  - A reduced-motion still.
- **Cost:** it runs at about 38ms of script per second in Chrome.

The original Ganesh Chaturthi showcase is unchanged.

## Fixed

- **`onUpdate` read the previous frame.** The stage ran callbacks before applying the
  frame, so an `onUpdate` reading a tweened object saw last frame's values; a count-up's
  final write could be one frame behind. Frames are now applied first.
- **`onComplete` on reverse.** A reversed timeline arriving back at its start called
  `onComplete`; it now calls `onReverseComplete`.

## Upgrade Notes
