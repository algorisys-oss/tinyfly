# v0.46.1

**Release Date:** 2026-07-31

Data-loss fix: auto-save stopped running after the first scene or project
switch, so saved projects could open with an empty canvas.

## The bug

Opening a project from the gallery — or creating one there, or switching scenes,
or entering/leaving a symbol edit — permanently disabled auto-save for the rest
of the session. Work done after that point only reached storage if something
triggered an explicit save (the toolbar **Save**, reopening the gallery, or the
tab-close flush). Reload without hitting one of those and the project came back
as it was at the last flush — often empty, since a brand-new project is empty at
the moment it's created.

## Cause

Both the auto-save and thumbnail effects skip a run while a scene/project switch
is in flight, using a plain `isSwitchingScene` flag:

```js
createEffect(() => {
  if (isSwitchingScene) return   // <- bails before reading anything
  store.tracks()
  store.duration()
  ...
})
```

Solid re-tracks an effect's dependencies on every run, so a run that returns
before reading a signal is left subscribed to **nothing** and never runs again.
The switch helpers set the flag and then write signals (`store.stop()`,
`loadTimeline`, `loadElements`) outside a `batch()`, and Solid flushes user
effects synchronously at the end of each such write — so the effect reliably ran
mid-switch, saw the flag, and unsubscribed itself. The flag is a plain variable
rather than a signal, so lowering it re-armed nothing.

## Fix

Both effects now read their tracked signals **before** the guard. A skipped run
keeps its subscriptions, so the next edit saves normally.

Verified against the real Solid client runtime: an effect observing a flag raised
only inside one synchronous block sees `[true, true]` — confirming the flush
happens mid-switch rather than after it.

## Note on already-affected projects

This fix stops further loss but cannot recover work that was never written to
storage. A project that already opens empty is empty in IndexedDB.

## Technical Details

| File | Description |
|------|-------------|
| `src/editor/editor.tsx` | Auto-save and thumbnail effects read their signals before the `isSwitchingScene` guard |
