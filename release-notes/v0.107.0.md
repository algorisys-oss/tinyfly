# v0.107.0

**Release Date:** 2026-10-12

Flowing cartoon hair that fits the scalp, turns naturally with the head and
follows the same character actions and story tracks as existing hairstyles.

## Added

- Three editable presets: `softSweep`, `flowingBob` and `cascadingWaves`.
- Scalp-attached cubic locks with tapered ends and per-lock flexibility,
  a soft supporting mass, uneven hems and subtle clean-look highlights.
- Public `HairLock` and `HairLockPoint` types; lock paths, `fall` and `shine`
  remain plain JSON and survive editor save/load.
- **Flowing Cartoon Hair** example: compare all three styles, quick head
  turns and settling, eight resting views, colours and drawing looks.
- Face type followed by Hairstyle selectors: simple and expressive round,
  soft angular, broad jaw and older expressive faces using public `FaceOptions`.
  The chosen combination is highlighted in the animation and shown in all
  eight resting views.
- A headless eight-view reference sheet and updated API/model guides.

## Fixed

- Follow-through keeps curved lock centers and ribbon edges outside the
  skull at extreme motion, with smooth clearance and pinned roots. Free
  hanging locks retain their follow-through and resting artwork stays unchanged.
- Scalp-relative clearance remains continuous when a deformed center crosses
  the skull's origin, preventing locks from snapping to the opposite side.

## Validation

- Root attachment, skull fit, swing direction, front/back coverage and
  deterministic rendering through all eight views and three drawing looks.
- Scripted walking, facing and dialogue with hair follow-through and JSON
  timeline playback; editable lock persistence in editor JSON.
- Browser checks cover animation, controls and mobile layout. Unit tests,
  production build and public type declarations pass.
- Regression coverage for collapsed-center continuity, face/hair selection,
  motion and drawing controls, listener cleanup and standalone example code.

## Upgrade Notes

- Existing hairstyle data and rendering remain compatible.
- `hairFollowTracks` also drives flexible short locks; set a lock's `follow`
  to `0` to pin it. Roots remain fixed while tips respond progressively.
- `length` changes the supporting mass; edit lock paths for their individual
  lengths and curls. Use `locks: []` to remove sculpted locks.
