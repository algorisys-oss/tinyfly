# v0.60.0

**Release Date:** 2026-09-14

The course at `/learn` is complete, from keyframes to an award-style landing page.
Staggers on per-element tweens are fixed, and there is a Ganesh Chaturthi showcase.

## Added

### Learn: the whole course

`/learn` now has 9 modules, 27 lessons and 64 checked steps. New in this release:

| Module | Steps |
|---|---|
| **The editor** | Build a track in the studio, ease a keyframe, add a second track, apply a preset, then write the same animation in code. Steps end with **More → Copy JSON** and pasting it into `play( … )` |
| **Motion craft** | Overlaps, stagger `amount`, a wind-up, `back.out` overshoot, springs, damping without wobble, 0.2s button presses |
| **Text and SVG** | `splitText` words and masked lines, `scrambleText`, `drawSVG`, `morphSVG`, `motionPath` |
| **Interaction** | Hover in and out, a magnetic pull with `quickTo`, `draggable` with bounds and inertia, `flip` on a layout change, a tweened object drawn on the ticker |
| **Scroll** | Reveals, `toggleActions`, a trigger per card, a scrubbed progress bar, smoothed scrub, a pinned section, skew by scroll speed |
| **Accessibility and performance** | A reduced-motion mode with `live.matchMedia`, fading instead of moving, focus parity for hover effects, transforms instead of layout properties, stopping a canvas off screen |
| **Capstone** | The Agency Landing Page, section by section: headline reveal and drift, a seamless marquee that leans with scroll speed, words lit by scroll, pinned horizontal work, count-ups, icons that draw in, a lightbox grown from its tile, spring letters |

Checks can now test interaction:

- `context.fire(selector, type)` fires real events.
- `context.calls(method)` lists the `live` calls the code made, with their arguments.
- `context.rerun({ reducedMotion })` runs the code again with the preference emulated.

Checks run on a hidden copy of the step, so a check that clicks or hovers never
changes the preview. Scroll previews scroll inside their own box
(`scroller: '.scroller'`), and pins work inside it.

## Fixed

### Staggers on per-element tweens

`drawSVG`, `morphSVG`, text tweens, plain objects and function values build one
tween per element. Two stagger problems affected them:

- **Delays piled up.** Each element's start grew with the elements before it. With
  38 strokes at `stagger: 0.025`, the 18th started at 3.8s instead of 0.43s.
- **`amount` and `from` were ignored.** `stagger: { amount: 1, from: 'center' }`
  started every element together.

Both now match a stagger on a single shared track.

### Line masks clip descenders

`splitText` line masks leave 0.12em below the baseline, so letters such as g, p
and y are no longer cut off.
