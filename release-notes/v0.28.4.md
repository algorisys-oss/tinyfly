# v0.28.4

**Release Date:** 2026-07-22

## Fixed

- **Dope Sheet track list now scrolls.** The Dope Sheet's container was missing
  the `height: 100%` / `min-height: 0` the Curves view has, so its track list had
  no bounded height — extra rows were clipped instead of scrolling. It now fills
  the timeline pane and scrolls vertically like the Curves view.

## Technical Details

| File | Description |
|------|-------------|
| `src/editor/components/timeline-view.css` | `.timeline-view` fills the panel; `.timeline-tracks` gets `min-height: 0` so it scrolls |

No engine or test changes — 645 tests passing.
