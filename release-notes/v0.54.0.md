# v0.54.0

**Release Date:** 2026-09-13

This release adds Flip, which completes the engine work for the GSAP demos. It
also adds editor samples that use the new engine features, and fixes text
colour in exported and embedded animations.

## Added

### Flip for live elements

GSAP's `Flip.getState` and `Flip.from`, plus a one-call form:

```ts
live.flip('.item', () => grid.classList.toggle('compact'), { duration: 0.6, stagger: 0.03 })

const state = live.getFlipState('.item')
renderNewOrder()
live.flipFrom(state, { targets: '.item' })
```

- **Any layout change works:** reordering the DOM, toggling classes, filtering
  with `display: none`, or resizing.
- **How it measures.** Before the change it records where each element
  appears, including any transform it is animating with. After the change it
  records where the element is laid out, ignoring transforms. Offsets are
  measured between centres, since scaling happens about the centre. Each
  element then gets an ordinary tween back to rest.
- **Interruptions are smooth.** A flip that starts while another is running
  takes over each element from where it appears.
- **New elements come in.** Elements that become visible get an `enter`
  animation (fade and grow by default, or your own start values, or none).
- **Options:** `duration`, `ease`, `stagger` in document order, `scale`
  (`false` moves elements without resizing them), and `onComplete`.

Measured in Chrome across four demos: 0.00 px of visible jump at the first
frame (with layouts moving up to 180 px), exact landing on the new layout, and
0.18 px of movement between frames when a shuffle was interrupted by a sort.

### Four Flip demos (33 GSAP-style demos in all)

| Demo | Shows |
|---|---|
| Flip: Shuffle Grid | Reorder the DOM (shuffle or sort); tiles glide to their new cells |
| Flip: Filter Gallery | Hide and show by category; items that stay glide, items that return fade in |
| Flip: Layout Switch | Grid, row and pile layouts, changed with CSS classes only |
| Flip: Expand Tile | One tile opens across the grid while the others reflow |

### Editor samples that use the new engine features

Five samples you can open in the editor and edit:

| Sample | Uses |
|---|---|
| Decode Headline | Text scrambles into place, an underline draws in, and a subtitle types on |
| Scramble Countdown | 3, 2, 1, GO! scrambling from each number to the next, with pulses and colour |
| Throw & Settle | Three inertia throws under different friction, snapping to a grid |
| Badge Morph | A circle morphs to a star, a hexagon and back, with sharp corners |
| Stats Decode | Dashboard figures decode while their bars grow |

Samples can now hold text tracks and inertia tracks, and opening a sample loads
them through the editor's own store actions.

## Fixed

- **Exported and embedded text coloured its background instead of the
  text.** The HTML generated for embeds, previews and Copy code omitted
  `data-element-type="text"`. The DOM adapter therefore treated an animated
  text `fill` as a background colour: "GO!" turning green painted a green box.
  Text elements are now marked, and the text itself changes colour.
- **The editor's `flip()` for authoring measured offsets from corners**, while
  scaling happens about the centre. An element that changed size landed off
  by half its change in size. It now measures between centres.
- **Copy code pages from this build pin to v0.54.0**, which is the first
  release whose CDN bundle includes `live.flip`. A Flip demo copied from a
  development build before this release pointed at v0.53.0, which has no Flip,
  so its buttons did nothing.

### Test Coverage

- 10 Flip tests with simulated layout: start and end positions, size changes
  with centred scale, move-only mode, unmoved elements left alone, stagger
  order, entering elements, skipping the entrance, a smooth interrupted flip,
  the two-step API, and `onComplete`.
- A test that the authoring `flip()` offsets by centres when an element
  resizes.
- 2 sample tests: text and inertia tracks load with their settings, and each
  new sample plays through to its intended end state.
- A DOM test that generated text HTML colours the text, not its background.
- Flip demos are marked as needing real layout. The unit tests run them and
  check that they tear down cleanly; their motion was measured in Chrome.
- In Chrome, all five new samples previewed on the Examples page. Decode
  Headline opened in the editor and scrubbed from LOADING through TINYFLY to
  "animation engine".
- 1,618 tests passing.
