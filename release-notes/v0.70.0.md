# v0.70.0

**Release Date:** 2026-09-15

Teaching figures can go full screen. A detailed diagram, with its steps and scenario
choices, can fill a laptop or phone screen instead of a column of a blog post.

## Added

### Full screen for teaching figures

- **Turning it on:** `data-fullscreen="true"` on a `[data-tinyfly-embed]` figure, or
  `createControls(player, figure, { fullscreen: true })`. It's off by default, so existing
  figures don't change.
- **Two routes:** the Fullscreen API where the browser supports element fullscreen, and a
  fixed overlay where it doesn't or refuses. iPhone Safari supports element fullscreen only
  on iPad (MDN browser-compat-data), so on an iPhone the overlay is what readers get. The
  overlay locks page scrolling, and Esc or the button closes it.
- **Layout:** the figure becomes a column. Controls and captions keep their size, and the
  SVG or canvas takes the rest of the screen, scaled to fit. The rules use `!important` so a
  host page's figure CSS can't keep the drawing small. `--tf-fullscreen-bg` sets the
  background.
- **Keys and labels:** F toggles it while focus is in the figure. The button uses
  `labels.fullscreen` and `labels.exitFullscreen`, with `aria-pressed`.
- **API:** `controls.fullscreen` has `enter()`, `exit()` and `active`. `FullscreenControl`
  is exported as a type.
