# v0.73.0

**Release Date:** 2026-09-27

The stick figure on the website and in the script-tag bundle. Try the poses in the
Examples gallery, or use them from a page with no build step.

```html
<script src="https://cdn.jsdelivr.net/gh/algorisys-oss/tinyfly@v0.73.0/cdn/tinyfly.iife.js"></script>
<script>
  const ctx = document.querySelector('canvas').getContext('2d')
  ctx.translate(120, 200)
  tinyfly.drawStickFigure(ctx, tinyfly.POSES.wave, { height: 160 })
</script>
```

## Added

- **`characters` in the browser bundle:** `tinyfly.iife.js` now carries the stick figure
  (`POSES`, `pose`, `blendPose`, `walkPose`, `talkingMouth`, `drawStickFigure`,
  `stickFigureTarget`, `poseTracks`) on the `tinyfly` global. About 5 kB.
- **Stick Figure gallery card** (Video category): pick a pose and watch it blend there,
  or let it step through all of them; toggle walking and talking. "Copy code" gives a
  standalone page that runs as-is.

## Changed

- **Narrated Scene card** now draws its figure with `tinyfly/characters`: `poseTracks()`
  turns "rest → wave → rest" into keyframes, and `walkPose` / `talkingMouth` add the
  walk and the chatter, in place of about 30 lines of hand-drawn canvas code.
- README, `llms.txt` and the guides say what the browser bundle includes.
