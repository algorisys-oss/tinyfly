# v0.16.0

**Release Date:** 2026-07-18

Minor release that adds **AI animation generation** — describe an animation in
plain language and get a fully editable timeline — plus **Esc closes any dialog**.

## Highlights

- **AI prompt → animation** - A new prompt bar under the scene tabs turns a
  natural-language brief ("a title that fades up with a shine", "three cards
  sliding in one after another") into a real tinyfly animation: elements plus a
  populated timeline you can edit like any hand-made one.
- **Bring your own key, three providers** - Works with **OpenAI**, **Google
  Gemini**, and **Anthropic**. Keys are entered in a new **AI Settings** dialog
  (the ⚙ in the prompt bar), stored only in your browser (`localStorage`,
  base64-obfuscated), and sent directly to the provider — no tinyfly server.
- **JSON-first, engine untouched** - The model emits tinyfly's sample schema
  (`{ elements, tracks, duration }`), which is validated and loaded through the
  exact same path as the sample library. All AI code lives in the editor layer;
  the animation engine has no AI dependency.
- **Esc closes any dialog** - Every dialog (AI Settings, Project Settings,
  Export, Embed, Samples, Shortcuts, Transition) now closes on Escape, from
  anywhere on the page — dialog dismissal takes precedence over the editor's
  other Escape shortcuts.

## Added

- Multi-provider LLM layer (`callLLM`) with adapters for OpenAI / Gemini /
  Anthropic, dependency-free (raw `fetch`).
- `generateAnimation(prompt)` — prompt → validated animation → loaded into the
  editor; strict JSON validation (element/track integrity) with tolerant parsing
  (strips markdown fences, extracts JSON from prose).
- `AIPromptBar` and `AISettingsDialog` editor components.
- `useEscapeClose(isOpen, onClose)` shared helper — a capture-phase,
  document-level Escape listener used by every dialog.

## Technical Details

### Changed / New Files

| File | Description |
|------|-------------|
| `src/editor/ai/ai-settings.ts` | Provider config, model lists, key storage (`tinyfly:ai:config`) |

| `src/editor/components/*-dialog.tsx` | All 7 dialogs wired to `useEscapeClose` |

### Test Coverage

- 544 tests passing (+10: AI animation parse/validate — fence-stripping,
  prose-wrapped JSON, and every rejection path: unknown track target, missing
  element name, empty elements, non-positive duration, empty keyframes, garbage).

### Known limitations (tracked in todo.md)

- Generated animations use shapes/text/lines/arrows only — no image/video
  elements (the model can't supply real media sources).
- No streaming responses or "refine this animation" follow-up turn yet.
- Direct browser calls depend on provider CORS (Anthropic uses the opt-in
  browser-access header; a blocked provider surfaces a clear error).
