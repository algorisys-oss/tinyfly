# v0.64.0

**Release Date:** 2026-09-14

tinyfly now makes explanatory, step-through teaching figures. The JSON gains markers
and captions. The player shows a frame on load, steps, respects reduced motion and
pauses off screen. New: step controls, one-script declarative embeds, diagram
primitives, and a `tinyfly` command to validate figures and render frames.

## Added

### Markers, captions and a stepping player

```json
"config": {
  "markers": [
    { "id": "full", "time": 1400, "label": "cap is full", "pause": true, "question": "What happens next?" }
  ]
},
"captions": { "es": { "full": "la capacidad está llena" } }
```

**Player methods:** `next()` (animated), `prev()`, `goToMarker(id)`, `currentMarker`,
`caption()` (in the page's `lang`) and `subscribe(listener)`.

**Player options:**

| Option | What it does |
|---|---|
| `initialFrame` | The frame shown on load: `'start'` (default), `'end'`, a time in ms, or `'none'` |
| `stepMode` | `play()` runs to the next marker and stops |
| `onMarker` | Called when the current marker changes |
| `captions` | Translations from a separate file, merged over the timeline's |
| `respectReducedMotion` | Default on: no autoplay, final frame, steps jump; follows changes to the setting |
| `playWhenVisible` | Pauses off screen and in hidden tabs; autoplay waits until first seen |

Markers with `pause` stop playback. Together with a `question` they give the
predict-then-reveal pattern.

### `tinyfly/embed` and `tinyfly-embed.iife.js`

```html
<figure data-tinyfly-embed data-options='{"stepMode": true}'>
  <svg viewBox="0 0 720 200">…</svg>
  <script type="application/json" data-tinyfly-timeline>{ … }</script>
  <figcaption>Appending to a full slice</figcaption>
</figure>
<script src="https://cdn.jsdelivr.net/gh/algorisys-oss/tinyfly@v0.64.0/cdn/tinyfly-embed.iife.js" data-tinyfly-auto></script>
```

- **Controls:**
  - Buttons and inputs: restart, previous and next step, play/pause, scrub, a step
    counter and speed.
  - A caption line announced with `aria-live`, and a question with a Reveal button.
  - Keys (Space, ←, →, Home) act only in the focused figure.
  - Styled through `--tf-ctl-*` custom properties, with labels passed in.
- **Declarative mounting:**
  - `mountAll()`, automatic with `data-tinyfly-auto`.
  - Attributes: `data-options`, `data-src`, `data-labels`, `data-controls` and
    `data-alt`, plus a `data-tinyfly-captions` script.
  - Embeds pause off screen by default, and each SVG becomes a labelled image.
- **Bundle size:** 19 kB gzipped, including the player.

### `tinyfly/teach`

```js
const slice = cells({ id: 's', values: [1, 2, 3, ''] })
const l = lesson({ id: 'append' })
l.marker('before', { label: 'len 3' })
slice.write(l, 3, 4)
l.marker('after', { label: 'len 4', pause: true, question: 'What is cap(s)?' })
```

- **`lesson()`** writes steps as keyframes with `to`, `set`, `wait`, `together`,
  `marker` and `initial`.
- **Diagram primitives** produce SVG markup plus step helpers: `cells` (array /
  slice), `pointer`, `stack`, `queue` (channel), `table` (map) and `pipeline`
  (middleware), wrapped by `figure`.

### The `tinyfly` command

```bash
npx tinyfly validate append.json --markup append.svg
npx tinyfly render append.json append.svg --at end > append-final.svg
```

- **`validate`** fails when:
  - a track targets an element the markup lacks;
  - markers are out of order, duplicated or out of range;
  - a keyframe comes after an explicit duration;
  - a caption names an unknown marker.
- **`render`** writes a frame into static markup, for RSS, email, print and previews.
  It needs no DOM.
- **Library use:** both are also exported as `validateEmbed` and `renderFrame`.

### Format version and SRI

- **`formatVersion`:** timeline JSON now carries `"formatVersion": 1`. A newer version
  is refused with a clear error, and the policy is documented.
- **SRI:** the CDN's `cdn/README.md` lists a hash for every bundle.

## Fixed

- **SVG `fill` and `stroke` on the player's DOM adapter.** On SVG elements they became
  `background-color` and `border-color`, which do nothing. They are now written as SVG
  paint, along with `strokeWidth`, `strokeDasharray` and `strokeDashoffset`.
- **A figure's first frame.** A loaded animation showed its raw markup until played or
  sought.

### Test Coverage

- **Unit:** 1,999 tests passing (17 new). They cover the player's teaching behaviour,
  controls, mounting, validation, static render, the lesson builder and primitives,
  and the format version.
- **Cross-browser (Chromium, Firefox, WebKit):** a new `embed` check covers:

  - captions in the page language;
  - SVG fill painted;
  - a labelled image;
  - autoplay waiting until seen and pausing off screen;
  - reduced motion.

## Upgrade Notes

- **Frame on load:** players now show a frame on load. Pass `initialFrame: 'none'` to
  keep the old behaviour.
- **Reduced motion:** under `prefers-reduced-motion: reduce`, players no longer autoplay
  and show the final frame. Pass `respectReducedMotion: false` to opt out.
- **Serialized output:** timelines now serialize with `formatVersion: 1`.
