# v0.34.0

**Release Date:** 2026-07-22

**Phase B begins: the Camera.** Animate a pan / zoom / rotate over the whole stage
— cinematic moves without touching your elements.

## Highlights

- **🎥 Camera.** A new button in the preview header adds a camera (click again to
  remove). It creates four tracks on a reserved **`Camera`** target — `x`, `y`
  (pan), `scale` (zoom), `rotate` — seeded at identity so the camera starts still.
  Keyframe them like any track (select a Camera track, add/drag keyframes, set
  values in the Property Panel) to push in, pan, or spin the stage.

## Design

True to tinyfly's "animation = a transform" ethos, the camera is just an animated
element: the preview wraps the stage in a reserved `Camera` layer registered with
the DOM adapter, so ordinary tracks targeting `Camera` transform everything at
once. With no camera tracks the layer is identity — completely inert. It
serializes for free (it's in the timeline JSON). See
[docs/camera.md](../docs/camera.md).

## Added

- `EditorStore.addCamera` / `removeCamera` / `hasCamera`.
- `Camera` layer in the DOM preview (registered with the adapter).
- Preview-header **Camera** toggle.

### Test Coverage

- 653 tests passing (+3 camera store tests: adds identity-seeded pan/zoom/rotate
  tracks, no-op when present, removes all camera tracks).

### Known limitations (this slice)

- Camera renders in the **DOM preview** only so far. Canvas/SVG previews, raster
  export and embeds come next.
- Editing elements while the playhead sits on a camera-transformed frame is
  approximate (the drag math assumes identity) — set up the scene first, then
  keyframe the camera.
