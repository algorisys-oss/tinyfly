# v0.29.0

**Release Date:** 2026-07-22

More room to design — the top bars reclaim vertical space.

## Highlights

- **Collapsible AI prompt bar.** The AI "Describe an animation…" bar is now hidden
  by default and toggled with a new **AI** button in the toolbar (or the **×** in
  the bar). It stays hidden/shown across sessions. Recovers a full row (~50px)
  when you're not generating.
- **Auto-hiding scene bar.** Single-scene projects no longer show a full scene bar
  — just a compact **+ Scene** button. The full scene bar (tabs, thumbnails,
  transitions) returns as soon as you have more than one scene.
- **Slimmer header.** The top toolbar row has tighter vertical padding.

Together these free up ~70–80px of vertical space on a typical single-scene
project — noticeably more canvas.

## Technical Details

| File | Description |
|------|-------------|
| `src/editor/editor.tsx` | AI-bar toggle (persisted), scene-bar auto-hide, wiring |
| `src/editor/components/toolbar.tsx` / `.css` | AI toggle button |
| `src/editor/components/ai-prompt-bar.tsx` / `.css` | Collapse (×) button |
| `src/editor/editor.css`, `scene-bar.css` | Slimmer header + scene bar |

No engine or test changes — 645 tests passing.
