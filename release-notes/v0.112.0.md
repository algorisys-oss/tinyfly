# v0.112.0 — Composable cricket plays and delivery context

Released: 2026-10-13

Cricket stories can now combine delivery legality, motion and an authored
candidate decision, keeping physical events separate from the final verdict.

## Added

- `cricketPlay(field, options)` and `cricketPlayClip(options)` compile independent
  delivery style/legality, shot/finish, fielding, current free-hit context and
  explicit candidate dismissal into owned JSON. Normalized `play` and `ruling`
  accompany the timeline/events/result. Omitted dismissal means no dismissal.
- No-ball/free-hit protection suppresses caught/bowled/LBW/stumped decisions and
  out signals while retaining physical catches, pad contacts and falling bails.
  Supported run-out remains available. Illegal free hits carry forward, legal
  ones consume context; Test rejects current free-hit context.
- Five live combinations: no-ball/stumps, free-hit/catch, no-ball/four,
  free-hit/run-out and free-hit/Wide. Test disables free-hit choices; exported
  story JSON includes the components, ruling, selected camera and captions.
- `CRICKET_PLAY_COMPONENTS`/`CRICKET_PLAY_EXAMPLES` discovery and public/model
  guides with an explicit supported-combination table. Wide currently supports
  keeper collection only; innings/score/strike/lesson state remains external.

## Fixed

- Release validation exposed a timeout in the existing 60-render organic contour
  test under concurrent load. That test now allows 15 seconds; all assertions
  and renderer behavior are unchanged.

## Compatibility

- Original sixteen action presets retain motion, results and captions.
- Both builders use the existing native rig/contact compiler and exact contact
  sampling; no browser, renderer, clock or UI dependency is added to the API.
